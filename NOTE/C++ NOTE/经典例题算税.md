# 经典例题：计算个人所得税

## 问题描述

根据员工工资计算个人所得税，按工资从高到低输出结果。

### 税率规则

**应纳税所得额** = 月工资 - 3500元（起征点）

| 级数 | 应纳税所得额 | 税率 | 速算扣除数 |
|:----:|:------------:|:----:|:----------:|
| 1 | ≤1500 | 3% | 0 |
| 2 | 1500~4500 | 10% | 105 |
| 3 | 4500~9000 | 20% | 555 |
| 4 | 9000~35000 | 25% | 1005 |
| 5 | 35000~55000 | 30% | 2755 |
| 6 | 55000~80000 | 35% | 5505 |
| 7 | >80000 | 45% | 13505 |

**计算公式**：`税额 = 应纳税所得额 × 税率 - 速算扣除数`

### 示例

```
输入：
张三 6500    李四 8000    王五 100000

输出（降序）：
王五应该缴纳的个人所得税是：32000.0
李四应该缴纳的个人所得税是：1350.0
张三应该缴纳的个人所得税是：0.0
```

## 完整代码实现

```cpp
#include <iostream>
#include <iomanip>
#include <vector>
#include <algorithm>
using namespace std;

class Employee {
private:
    string name;
    double salary;
public:
    Employee(string n, double s) : name(n), salary(s) {}
    string getName() const { return name; }
    double getSalary() const { return salary; }
};

bool cmp(const Employee& e1, const Employee& e2) {
    return e1.getSalary() > e2.getSalary();  // 降序排序
}

void printTax(const Employee& e) {
    double t = e.getSalary() - 3500;
    double tax = 0.0;

    if (t > 0 && t <= 1500) tax = t * 0.03;
    else if (t <= 4500) tax = t * 0.10 - 105;
    else if (t <= 9000) tax = t * 0.20 - 555;
    else if (t <= 35000) tax = t * 0.25 - 1005;
    else if (t <= 55000) tax = t * 0.30 - 2755;
    else if (t <= 80000) tax = t * 0.35 - 5505;
    else if (t > 80000) tax = t * 0.45 - 13505;

    cout << fixed << setprecision(1);
    cout << e.getName() << "应该缴纳的个人所得税是：" << tax << endl;
}

int main() {
    vector<Employee> emp = {
        Employee("张三", 6500),
        Employee("李四", 8000),
        Employee("王五", 100000)
    };

    sort(emp.begin(), emp.end(), cmp);
    for_each(emp.begin(), emp.end(), printTax);

    return 0;
}
```

## 核心技术要点

### 1. 类封装与访问控制

```cpp
class Employee {
private:          // 数据封装，外部不可直接访问
    string name;
    double salary;
public:           // 提供公有接口
    Employee(string n, double s) : name(n), salary(s) {}  // 构造函数初始化列表
    string getName() const { return name; }   // const成员函数
    double getSalary() const { return salary; }
};
```

**关键点**：
- `private` 实现数据隐藏，防止外部直接修改
- 使用**初始化列表**比赋值效率更高
- `const` 成员函数承诺不修改对象状态
- getter 方法提供受控的只读访问

### 2. 自定义排序策略

```cpp
bool cmp(const Employee& e1, const Employee& e2) {
    return e1.getSalary() > e2.getSalary();  // 返回true表示e1排在e2前
}
```

**使用方式**：`sort(vec.begin(), vec.end(), cmp);`

**设计原则**：
- 参数使用 **const引用** 避免拷贝开销
- 返回值语义：`true` → e1优先于e2（降序）
- 可替换为 lambda：`[](auto& a, auto& b){ return a.getSalary() > b.getSalary(); }`

### 3. 分级税率计算逻辑

```cpp
double t = salary - 3500;  // 应纳税所得额
if (t <= 0) tax = 0;       // 未达起征点
else if (t <= 1500) tax = t * 0.03;
else if (t <= 4500) tax = t * 0.10 - 105;
// ... 依次判断各税率区间
```

**算法特点**：
- 使用 **if-else if 链** 实现区间判断
- 利用**速算扣除数**简化累进计算（避免逐级分段计算）
- 注意边界条件：`t <= 0` 时免税

### 4. STL算法组合应用

```cpp
sort(begin, end, cmp);           // O(n log n) 排序
for_each(begin, end, func);      // O(n) 遍历执行
```

**技术细节**：
- `sort` 基于**快速排序/内省排序**，平均时间复杂度 O(n log n)
- `for_each` 对每个元素调用一元函数，等价于范围for循环
- 迭代器提供统一的容器遍历接口

### 5. 输出格式化控制

```cpp
cout << fixed << setprecision(1);  // 固定小数位，保留1位
```

**作用域**：设置后持续生效，直到下次更改格式状态。

## 常见错误与陷阱

### ❌ 排序方向错误
```cpp
// 错误：升序（从小到大）
return e1.getSalary() < e2.getSalary();
// 正确：降序（从大到小）
return e1.getSalary() > e2.getSalary();
```

### ❌ 忽略起征点
```cpp
// 错误：直接对工资征税
tax = salary * rate;
// 正确：先减起征点
double t = salary - 3500;
if (t > 0) tax = t * rate - deduction;
```

### ❌ 精度丢失
```cpp
// 错误：默认输出可能显示科学计数法或过多小数位
cout << tax << endl;
// 正确：固定格式 + 指定精度
cout << fixed << setprecision(1) << tax << endl;
```

### ❌ 封装破坏
```cpp
// 错误：公共成员变量
class Employee { public: string name; };
// 正确：私有数据 + 公有接口
class Employee { private: string name; public: string getName(); };
```

## 优化方案对比

### 方案1：结构体数组替代if-else链 ⭐推荐

```cpp
struct TaxBracket { double upper; double rate; double deduction; };

constexpr TaxBracket brackets[] = {
    {1500, 0.03, 0}, {4500, 0.10, 105}, {9000, 0.20, 555},
    {35000, 0.25, 1005}, {55000, 0.30, 2755},
    {80000, 0.35, 5505}, {INT_MAX, 0.45, 13505}
};

double calcTax(double income) {
    double t = income - 3500;
    if (t <= 0) return 0;
    for (auto& b : brackets)
        if (t <= b.upper) return t * b.rate - b.deduction;
    return 0;
}
```
**优势**：数据与逻辑分离，易于维护；消除冗余条件判断。

### 方案2：Lambda表达式简化

```cpp
sort(emp.begin(), emp.end(), [](const auto& a, const auto& b) {
    return a.getSalary() > b.getSalary();
});
```
**优势**：就地定义，无需额外函数；闭包可捕获上下文变量。

### 方案3：输入验证增强

```cpp
Employee(string n, double s) : name(n), salary(s) {
    if (n.empty()) throw invalid_argument("姓名不能为空");
    if (s < 0) throw invalid_argument("工资不能为负");
}
```

### 方案4：文件I/O扩展

```cpp
// 从文件读取员工数据
vector<Employee> loadFromFile(string filename) {
    vector<Employee> v; ifstream f(filename);
    string name; double sal;
    while (f >> name >> sal) v.emplace_back(name, sal);
    return v;
}
```

## 扩展思考

### 1. 多维度排序支持
```cpp
enum SortMode { BY_SALARY, BY_NAME, BY_TAX };

void sortBy(vector<Employee>& v, SortMode mode) {
    switch(mode) {
        case BY_SALARY: sort(v.begin(), v.end(),
            [](auto& a, auto& b){ return a.getSalary() > b.getSalary(); }); break;
        case BY_NAME: sort(v.begin(), v.end(),
            [](auto& a, auto& b){ return a.getName() < b.getName(); }); break;
        // ... 其他模式
    }
}
```

### 2. 批量计算与结果导出
```cpp
struct TaxResult { string name; double tax; };
vector<TaxResult> batchCalc(const vector<Employee>& emp) {
    vector<TaxResult> res;
    for (auto& e : emp) {
        double t = e.getSalary() - 3500;
        res.push_back({e.getName(), calcTax(t)});
    }
    return res;
}
```

## 总结

### 核心知识点

| 知识点 | 关键技术 | 应用场景 |
|:------:|:---------|:---------|
| **类封装** | private数据 + public接口 | 数据保护与访问控制 |
| **自定义排序** | 比较函数/lambda | 多条件排序需求 |
| **分级算法** | if-else if链/查表法 | 区间划分计算 |
| **STL算法** | sort + for_each | 容器操作标准化 |
| **格式化I/O** | fixed + setprecision | 数值精度控制 |

### 最佳实践建议

1. ✅ **优先使用初始化列表**：比构造函数体内赋值更高效
2. ✅ **const正确性**：只读成员函数加const修饰
3. ✅ **const引用传参**：避免大对象拷贝开销
4. ✅ **数据驱动设计**：税率表等配置数据用结构体数组管理
5. ✅ **异常处理**：对输入参数进行有效性验证

### 学习价值

本例综合运用了C++面向对象编程和泛型编程范式：
- **OOP特性**：封装、访问控制、构造函数
- **STL组件**：vector容器、sort/for_each算法、迭代器
- **现代C++**：lambda表达式、auto类型推导、初始化列表
- **工程实践**：代码复用、模块化设计、可维护性
