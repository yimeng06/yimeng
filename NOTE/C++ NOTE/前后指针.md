# 前后指针技巧

**核心思想**：两个指针一前一后，用于定位目标节点的前驱，方便删除操作。

---

## 一、删除给定节点

**题目**：已知要删的节点指针，无法访问前驱节点。

```cpp
void deleteNode(ListNode* node) {
    auto nxt = node->next;
    *node = *nxt;       // 把下一个节点的值复制过来
    delete nxt;          // 释放下一个节点（防内存泄漏）
}
```

**原理**：无法删除当前节点（找不到前驱），所以用下一个节点"覆盖"当前节点，再删掉下一个。这是面试经典题。

---

## 二、删除倒数第N个节点

**题目**：删除链表倒数第n个节点。

```cpp
ListNode* removeNthFromEnd(ListNode* head, int n) {
    ListNode dummy(0, head);           // 哨兵节点，处理删头的情况
    ListNode* left = &dummy, *right = &dummy;

    while (n--) right = right->next;   // right先走n步

    while (right->next) {              // left和right一起走
        left = left->next;
        right = right->next;
    }                                   // 此时left在倒数第n+1个位置

    ListNode* nxt = left->next;         // nxt就是要删的节点
    left->next = left->next->next;      // 跳过nxt
    delete nxt;
    return dummy.next;
}
```

**原理**：right先走n步，然后left/right同步走。当right到末尾时，left恰好在倒数第n+1位（即待删节点的前驱）。

---

## 三、删除重复元素（保留一个）

**题目**：排序链表去重，每个值只保留一个。如 `1→1→2→3→3` → `1→2→3`

```cpp
ListNode* deleteDuplicates(ListNode* head) {
    ListNode* cur = head;
    while (cur && cur->next) {
        if (cur->next->val == cur->val)
            cur->next = cur->next->next;   // 跳过重复
        else
            cur = cur->next;               // 不同则前进
    }
    return head;
}
```

**原理**：cur看下一个节点，相同就跳过，不同就前移。

---

## 四、删除所有重复元素（全部移除）

**题目**：有重复的值全部删除。如 `1→1→1→2→3` → `2→3`

```cpp
ListNode* deleteDuplicates(ListNode* head) {
    ListNode dummy(0, head);
    ListNode* cur = &dummy;

    while (cur->next && cur->next->next) {
        if (cur->next->val == cur->next->next->val) {
            int val = cur->next->val;
            while (cur->next && cur->next->val == val)
                cur->next = cur->next->next;   // 连续跳过所有等于val的
        } else {
            cur = cur->next;
        }
    }
    return dummy.next;
}
```

**关键**：必须用哨兵节点，因为头节点可能被删除。

---

## 总结

| 题目 | 技巧 | 关键 |
|:-----|:-----|:-----|
| **删除给定节点** | 值覆盖 | 用下一个节点覆盖当前，再删下一个 |
| **删倒数第N个** | 左右间距n | right先走n步，再同步走 |
| **去重（保留一个）** | 单指针+前看 | 相同就跳过 |
| **去重（全删除）** | 哨兵+连续跳过 | 头可能被删，必须用dummy |

**通用模式**：前后指针的核心是让前面的指针停在**目标的前驱位置**，方便执行 `prev->next = prev->next->next`。
