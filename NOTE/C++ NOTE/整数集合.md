# set（有序集合）

**一句话**：自动去重 + 自动排序的容器，底层是红黑树。

## 三大特性

| 特性 | 说明 | 时间复杂度 |
|:-----|:-----|:-----------|
| **自动去重** | 相同元素只存一份 | O(log n) |
| **自动排序** | 从小到大排列（默认） | 插入即有序 |
| **快速查找** | 二叉搜索树，查找高效 | O(log n) |

## 常用操作

```cpp
set<int> s;

s.insert(10);          // 插入
s.erase(20);           // 删除
s.count(10);           // 存在返回1，不存在返回0（只有0和1两种结果）
s.size();              // 元素个数
s.find(3) != s.end();  // find返回迭代器，找到就不是end → 存在

for (auto x : s) {     // 遍历：从小到大输出
    cout << x << " ";
}
```

> **注意**：`count()` 返回的是0或1（不是出现次数！），因为set里每个元素最多一个。想查次数用 `multiset` 或 `unordered_map`。

## 查找神器：lower_bound & upper_bound

这两个函数在**有序容器**里非常好用：

```cpp
set<int> s = {1, 3, 5, 7, 9};
```

| 函数 | 含义 | 给3 | 给5 | 给10 |
|:-----|:-----|:----:|:----:|:----:|
| `lower_bound(x)` | 第一个 **≥** x 的位置 | → **3** | → **5** | → end |
| `upper_bound(x)` | 第一个 **>** x 的位置 | → **5** | → **7** | → end |

**口诀**：
- `lower_bound` = "大于等于" = **下限**（可以等于你）
- `upper_bound` = "严格大于" = **上限**（必须超过你）

### 实战场景：找区间 [a, b] 内的所有元素

```cpp
auto left = s.lower_bound(a);   // 第一个 ≥ a 的
auto right = s.upper_bound(b);  // 第一个 > b 的
// [left, right) 就是所有在 [a, b] 范围内的元素
```
