# 数组快捷定义

## 一维数组

```cpp
int a[6]{};          // 6个元素，全初始化为0
int b[10] = {0};     // 10个元素，全0（效果同上）
int c[] = {1,2,3};   // 3个元素，编译器自动数个数
```

## 二维数组

```cpp
int arr[3][4]{};                    // 3行4列，全0
int matrix[2][2] = {0};             // 2行2列，全0
int arr2[][3] = {{1,2,3},{4,5,6}}; // 2行3列，行数可省略，列数必须写
```

**要点**：`{}` 和 `= {0}` 效果相同——全部归零；`{1,2,3}` 则按给定的值初始化。
