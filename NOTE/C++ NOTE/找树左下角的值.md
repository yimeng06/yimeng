# 找树左下角的值

**题目**：找二叉树**最底层、最左边**的节点值。

## 解法：BFS（层序遍历）—— 反着入队

**核心技巧**：正常BFS是"先左后右"入队，我们反过来——**先右后左**入队。这样每层的最后一个出队的，就是该层的最左节点。最后一层的最后一个，就是答案！

```
        1
       / \
      2   3          正常BFS：1,2,3 → 左下角是2
     / \   \
    4   5   6        先右后左：1,3,2,5,4 → 最后出队的是4 ✅
```

```cpp
int findBottomLeftValue(TreeNode* root) {
    TreeNode* node;
    queue<TreeNode*> q;
    q.push(root);

    while (!q.empty()) {
        node = q.front();     // 取队首
        q.pop();

        if (node->right) q.push(node->right);   // ⚠️ 先进右孩子！
        if (node->left)  q.push(node->left);    // 再进左孩子！
    }
    return node->val;           // 最后一个出队的就是答案
}
```

**为什么有效？**
- 每层内部：右先进 → 左后进 → **左最后出**
- 层与层之间：上层先处理完 → **最后一层的左节点最终胜出**

时间O(n)，空间O(n)（队列最多存一层节点）。
