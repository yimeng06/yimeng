## 一、引用 (&)

```cpp
int x = 10;
int& ref = x;    // ref是x的别名
ref = 20;        // x也变成20——同一个东西
```

> 详细用法见 [首先引入语法.md](./首先引入语法.md)，这里只记最基本语法。

## 二、跳转三剑客

| 关键字 | 作用 | 口诀 |
|:-------|:-----|:-----|
| `break` | 跳出整个循环/switch | **我不玩了，回家！** |
| `continue` | 跳过本次循环，进入下一次 | **这局跳过，玩下一局！** |
| `goto` | 无条件跳转到指定标签 | **我要瞬间移动到那里！** |

和C语言一模一样，没啥新花样。

## 三、命名空间 (namespace)

防止名字冲突——你家狗叫"旺财"，我家狗也叫"旺财"，没关系，加上前缀就行。

### 定义

```cpp
namespace yimu {
    int age = 18;

    void fun() {
        cout << "age=" << age << endl;
    }

    namespace sun_yimu {          // 命名空间还能嵌套！
        void fun() {
            cout << "sun_yimu函数" << endl;
        }
    }
}
```

### 使用 —— `::` 作用域运算符

```cpp
yimu::fun();              // 调用yimu里的fun
yimu::sun_yimu::fun();    // 嵌套调用，一层层找
```

> `::` 就像地址：`小区::单元::房间号`，告诉编译器去哪找人。

## 四、保留小数位数

需要头文件 `#include <iomanip>`

```cpp
double c = 3.14159;
cout << fixed << setprecision(2) << c;   // 输出 3.14
```

| 函数 | 作用 |
|:-----|:-----|
| `fixed` | 固定小数点格式（不用科学计数法）|
| `setprecision(n)` | 保留n位小数 |

两个连用才能生效，缺一不可。
