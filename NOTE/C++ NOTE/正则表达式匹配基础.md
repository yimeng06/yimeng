# 正则表达式匹配（DP）

**题目**：实现支持 `.` 和 `*` 的正则匹配，必须**完全匹配**整个字符串。

| 符号 | 含义 | 示例 |
|:----:|:-----|:-----|
| `.` | 匹配任意**单个**字符 | `a.c` → "abc"、"axc" 都行 |
| `*` | 匹配**零个或多个**前面的元素 | `a*` → ""、"a"、"aaa" 都行 |

> `*` 前面必须有东西，它修饰的是前一个字符，不是独立存在的。

---

## 解法：动态规划

**状态定义**：`dp[i][j]` = s的前i个字符 能否 匹配 p的前j个字符

```
        p:  (空)  a  *  b  .  c
s:(空)   T     F  T  F  F  F
  a      F     F  T  F  F  F
  a      F     F  F  T  F  F
  b      F     F  F  F  T  F
  c      F     F  F  F  F  T  ← 答案在这里！
```

```cpp
bool isMatch(string s, string p) {
    int m = s.size() + 1, n = p.size() + 1;    // +1：留出第0行/列给空串
    vector<vector<bool>> dp(m, vector<bool>(n, false));

    dp[0][0] = true;                            // 空串匹配空串

    // 初始化第0行：空s能否匹配p的前j个？
    // 只有形如 a*b*c*... 的模式才能匹配空串（*把前面字符消掉）
    for (int j = 2; j < n; j += 2)
        dp[0][j] = dp[0][j - 2] && p[j - 1] == '*';

    // 填表
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            if (p[j - 1] == '*') {
                // 情况1：*匹配0次 → 跳过 "x*" 这两个字符
                // 情况2：*匹配多次 → s当前字符得匹配x，且dp[i-1][j]也得true
                dp[i][j] = dp[i][j - 2]
                    || dp[i - 1][j] && (s[i - 1] == p[j - 2] || p[j - 2] == '.');
            } else {
                // 普通：当前字符直接匹配
                dp[i][j] = dp[i - 1][j - 1]
                    && (p[j - 1] == '.' || s[i - 1] == p[j - 1]);
            }
        }
    }
    return dp[m - 1][n - 1];                    // 右下角就是答案
}
```

---

## 状态转移图解

```
遇到 '*' 时（p[j-1]=='*'）：
                    ┌─ 匹配0次：不要这个x*了 → 看 dp[i][j-2]
dp[i][j] ───────────┤
                    └─ 匹配多次：s[i-1]得等于x → 看 dp[i-1][j]

遇到普通字符或'.'时：
dp[i][j] = dp[i-1][j-1] && 当前字符能匹配上
```

---

## 总结

| 要点 | 说明 |
|:-----|:-----|
| **时间复杂度** | O(m×n)，m=s长度，n=p长度 |
| **空间复杂度** | O(m×n)（可优化到O(n)）|
| **初始化关键** | 第0行处理 `a*b*c*` 这种能匹配空串的模式 |
| **最容易错的地方** | `*` 是跟**前面一个字符**绑定使用的，不能单独出现 |
