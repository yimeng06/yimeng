# 经典例题：十进制转十六进制

## 问题描述

将输入的十进制整数转换为十六进制字符串。

### 十六进制规则

使用16个符号表示数值：`0-9`（数值0-9）+ `A-F`（数值10-15）

| 十进制 | 0-9 | 10 | 11 | 12 | 13 | 14 | 15 |
|:------:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|
| **十六进制** | 0-9 | A | B | C | D | E | F |

### 示例

```
输入：255   输出：FF
输入：26    输出：1A
输入：16    输出：10
输入：0     输出：0（需特殊处理）
```

---

## 核心算法：除16取余法

### 算法原理

**不断除以16，记录余数，最后反转结果**

以 `n = 26` 为例：
```
26 ÷ 16 = 1 ... 余10 → 'A'   （低位）
1 ÷ 16 = 0 ... 余1  → '1'    （高位）
─────────────────────────────
结果：1A（从下往上读）
```

### 关键步骤

1. **取余**：`n % 16` 得到当前位（0-15）
2. **转字符**：
   - 0-9 → `'0'-'9'`：`mod + '0'`
   - 10-15 → `'A'-'F'`：`mod - 10 + 'A'`
3. **拼接**：字符插入到字符串**前面**（因为先算出的是低位）
4. **更新**：`n /= 16`，继续处理高位
5. **终止**：`n == 0` 时停止

---

## 完整代码实现

```cpp
#include <iostream>
#include <string>
using namespace std;

string toHex(int n) {
    if (n == 0) return "0";  // 边界条件
    
    const char hexChars[] = "0123456789ABCDEF";  // 查找表
    string res = "";
    
    while (n != 0) {
        res = hexChars[n % 16] + res;  // 取余+查表+前插
        n /= 16;
    }
    
    return res;
}

int main() {
    int n;
    cin >> n;
    cout << toHex(n) << endl;
    return 0;
}
```

## 核心技术要点

### 1. 查找表优化 ⭐推荐

```cpp
const char hexChars[] = "0123456789ABCDEF";
char c = hexChars[mod];  // O(1)查表替代if-else
```

**优势**：
- 消除条件分支，代码更简洁
- 利用数组索引直接映射，效率高
- 易于扩展（如支持小写字母：`"0123456789abcdef"`）

### 2. 字符串前插操作

```cpp
res = hexChars[n % 16] + res;  // 新字符在前
```

**原因**：除法从低位到高位计算，必须反转顺序。

**替代方案**：后插 + 最后统一反转
```cpp
res += hexChars[n % 16];           // 后插（更高效）
reverse(res.begin(), res.end());   // 统一反转
```

### 3. ASCII码转换原理

```cpp
// 数字→字符：利用ASCII码连续性
'0' + 0 = '0'  (ASCII 48)
'0' + 9 = '9'  (ASCII 57)
'A' + 0 = 'A'  (ASCII 65)
'A' + 5 = 'F'  (ASCII 70)
```

### 4. 边界条件处理

| 输入 | 处理方式 | 输出 |
|:----:|:---------|:-----:|
| `n > 0` | 正常循环 | 十六进制字符串 |
| `n == 0` | 特判返回 `"0"` | `"0"` |
| `n < 0` | 先取绝对值，加负号前缀 | `"-XX"` |

## 复杂度分析

| 指标 | 复杂度 | 说明 |
|:----:|:------:|:-----|
| 时间 | **O(log₁₆ n)** | 每次循环n缩小16倍 |
| 空间 | **O(log₁₆ n)** | 存储结果字符串 |

**示例**：n=255时，log₁₆255 ≈ 2，循环2次得到"FF"

## 常见错误与陷阱

### ❌ 错误1：拼接顺序错误

```cpp
// 错误：后插导致结果反转
res = res + c;  // 得到 "AF" 而非 "1A"

// 正确：前插保持正确顺序
res = c + res;  // 或使用 reverse()
```

### ❌ 错误2：忽略n=0边界

```cpp
// 问题：返回空字符串 ""
while (n != 0) { ... }

// 正确：特殊处理
if (n == 0) return "0";
```

### ❌ 错误3：字符转换错误

```cpp
// 错误：直接赋值，实际存的是整数值
char c = mod;  // mod=10时，c是换行符而非'A'

// 正确：ASCII码偏移
char c = (mod < 10) ? (mod + '0') : (mod - 10 + 'A');
```

### ❌ 错误4：未处理负数

```cpp
// 问题：负数取模行为依赖编译器
int mod = n % 16;  // n=-26时，mod可能是-10或6

// 正确：先转为正数
if (n < 0) return "-" + toHex(-n);
```

## 实现方案对比

### 方案1：查找表法 ⭐推荐（已展示）

**特点**：代码简洁、高效、易维护

### 方案2：递归实现

```cpp
string toHex(int n) {
    if (n == 0) return "";
    const char hc[] = "0123456789ABCDEF";
    return toHex(n / 16) + string(1, hc[n % 16]);
}
```
**优势**：代码极简，无需手动反转  
**劣势**：递归深度O(log n)，大数可能栈溢出

### 方案3：C++标准库（工程首选）

```cpp
#include <sstream>
#include <iomanip>

string toHex(int n) {
    stringstream ss;
    ss << hex << uppercase << n;  // 一行搞定
    return ss.str();
}
```
**优势**：处理所有边界情况，性能最优  
**适用**：生产环境，不限制使用库函数

### 方案4：通用进制转换器

```cpp
string toBase(int n, int base) {
    if (n == 0) return "0";
    const char chars[] = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ";
    string res = "";
    while (n != 0) {
        res = chars[n % base] + res;
        n /= base;
    }
    return res;
}
// 使用：toBase(255, 16) → "FF", toBase(8, 2) → "1000"
```

## 扩展应用场景

### 1. 内存地址显示
```cpp
void printAddress(void* ptr) {
    cout << "0x" << toHex(reinterpret_cast<uintptr_t>(ptr)) << endl;
}
```

### 2. 颜色值转换（RGB ↔ HEX）
```cpp
string rgbToHex(int r, int g, int b) {
    auto pad = [](string s){ return string(2-s.size(), '0') + s; };
    return "#" + pad(toHex(r)) + pad(toHex(g)) + pad(toHex(b));
}
// rgbToHex(255, 128, 0) → "#FF8000"
```

### 3. 校验和计算（常见于通信协议）
```cpp
string checksum(const vector<int>& data) {
    int sum = 0;
    for (int x : data) sum += x;
    return toHex(sum & 0xFF);  // 取低8位
}
```

## 总结

### 核心知识点图谱

| 知识域 | 关键技术 | 要点 |
|:------:|:---------|:-----|
| **算法** | 除基取余法 | 通用进制转换核心思想 |
| **数据结构** | 查找表(O(1)映射) | 替代条件分支的优雅方案 |
| **字符串操作** | 前插/后插+反转 | 注意字符顺序 |
| **ASCII编码** | 字符-数字转换 | 利用码值连续性 |
| **边界处理** | 零值/负数/大数 | 鲁棒性关键 |

### 最佳实践清单

- ✅ **优先使用查找表**：消除if-else，提升可读性
- ✅ **处理n=0特例**：避免返回空字符串
- ✅ **考虑负数兼容**：根据需求决定是否支持
- ✅ **选择合适实现**：
  - 学习算法 → 手写查找表法
  - 工程项目 → 使用标准库 `stringstream`
  - 通用需求 → 扩展为任意进制转换器
- ✅ **性能敏感场景**：用后插+reverse替代多次前插

本例涵盖**基础算法思维**到**工程实践**的完整链条：
1. **数学基础**：进制转换原理（除基取余）

3. **代码质量**：边界条件、错误处理、可维护性
4. **扩展能力**：通用化设计、库函数选择权衡

**典型应用**：调试输出、协议解析、图形学（颜色）、嵌入式开发（寄存器地址）。
