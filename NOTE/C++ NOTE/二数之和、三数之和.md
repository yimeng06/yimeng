# 二数之和与三数之和

## 题目一：三数之和

### 问题描述

给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k`，同时还满足 `nums[i] + nums[j] + nums[k] == 0`。

请你返回所有和为 0 且不重复的三元组。

**注意**：答案中不可以包含重复的三元组。

### 算法思路

使用 **排序 + 双指针** 的方法来解决这个问题。

#### 核心思想
1. **先排序**：将数组排序，这样可以方便地跳过重复元素和使用双指针
2. **固定第一个数**：外层循环固定第一个数 `nums[i]`
3. **双指针寻找后两个数**：在 `i+1` 到 `n-1` 的范围内使用双指针寻找另外两个数
4. **剪枝优化**：通过判断边界情况提前终止循环

#### 剪枝策略
- **跳过重复元素**：`if (i && x == nums[i-1]) continue;` 避免重复计算
- **提前终止**：`if (x + nums[i+1] + nums[i+2] > 0) break;` 如果当前数加上后面两个最小的数都大于0，后面肯定没戏
- **跳过不可能情况**：`if (x + nums[n-1] + nums[n-2] < 0) continue;` 如果当前数加上后面两个最大的数都小于0，当前数太小，继续尝试下一个数

#### 双指针逻辑
- 如果三数之和 `s > 0`：说明需要更小的数，`k--`
- 如果三数之和 `s < 0`：说明需要更大的数，`j++`
- 如果三数之和 `s == 0`：找到一个解，记录后跳过重复元素

### 代码实现

```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        ranges::sort(nums); // 排序
        vector<vector<int>> ans;
        int n = nums.size();
        
        for (int i = 0; i < n - 2; i++) {
            int x = nums[i];
            if (i && x == nums[i - 1]) continue; // 跳过重复的数字
            if (x + nums[i + 1] + nums[i + 2] > 0) break; // 如果x太大，后面的数字都太小，肯定没戏
            if (x + nums[n - 1] + nums[n - 2] < 0) continue; // 如果x太小，后面的数字都太大，肯定没戏，但还能变大所以是continue
            
            int j = i + 1, k = n - 1;
            while (j < k) {
                int s = x + nums[j] + nums[k];
                if (s > 0) {
                    k--;
                } else if (s < 0) {
                    j++;
                } else { // 三数之和为0
                    ans.push_back({x, nums[j], nums[k]});
                    for (j++; j < k && nums[j] == nums[j - 1]; j++); // 跳过重复的数字
                    for (k--; k > j && nums[k] == nums[k + 1]; k--); // 跳过重复的数字
                }
            }
        }
        return ans;
    }
};
```

### 复杂度分析

- **时间复杂度**：O(n²)，其中 n 是数组的长度。排序需要 O(n log n)，双指针遍历需要 O(n²)。
- **空间复杂度**：O(1)，不考虑返回结果的空间，只使用了常数级别的额外空间。

### C++20 ranges::sort 补充说明

`ranges::sort(nums)` 是 C++20 引入的排序算法库，可以代替传统的 `sort()` 函数。

**头文件**：`<algorithm>`

**优势**：可以节省代码量，语法更简洁。

**对比示例**：
```cpp
// 原始的 sort() 函数
sort(nums.begin(), nums.end());

// 使用 ranges 可以简化为
ranges::sort(nums); // 从小到大排序
```

## 题目二：两数之和 II - 输入有序数组

### 问题描述

给你一个下标从 1 开始的整数数组 `numbers`，该数组已按 **非递减顺序排列**，请你从数组中找出满足相加之和等于目标数 `target` 的两个数。

如果设这两个数分别是 `numbers[index1]` 和 `numbers[index2]`，则 `1 <= index1 < index2 <= numbers.length`。

以长度为 2 的整数数组 `[index1, index2]` 的形式返回这两个整数的下标 `index1` 和 `index2`。

你可以假设每个输入 **只对应唯一的答案**，而且你 **不可以重复使用相同的元素**。

### 算法思路

使用 **双指针法** 来解决这个问题。

#### 核心思想
- **左指针**：从数组开头开始，指向较小的数
- **右指针**：从数组末尾开始，指向较大的数
- **根据和的大小调整指针**：
  - 如果两数之和 `s == target`：找到答案，返回结果
  - 如果两数之和 `s > target`：说明需要更小的数，右指针左移 `right--`
  - 如果两数之和 `s < target`：说明需要更大的数，左指针右移 `left++`

#### 为什么双指针有效？
由于数组已经排序，我们可以利用这个性质：
- 如果当前和大于目标值，我们需要减小和，所以移动右指针（选择更小的数）
- 如果当前和小于目标值，我们需要增大和，所以移动左指针（选择更大的数）
- 这样每次都能排除一半的可能性，保证不会错过正确答案

### 代码实现

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& numbers, int target) {
        int left = 0, right = numbers.size() - 1;
        
        while (true) {
            int s = numbers[left] + numbers[right];
            if (s == target) {
                return {left + 1, right + 1}; // 题目要求下标从1开始
            }
            s > target ? right-- : left++;
        }
    }
};
```

### 复杂度分析

- **时间复杂度**：O(n)，其中 n 是数组的长度。双指针最多遍历数组一次。
- **空间复杂度**：O(1)，只使用了常数级别的额外空间。

## 两种方法的对比

| 题目 | 方法 | 时间复杂度 | 空间复杂度 | 关键技巧 |
|------|------|------------|------------|----------|
| 三数之和 | 排序 + 双指针 | O(n²) | O(1) | 固定一个数，双指针寻找另外两个数 |
| 两数之和 II | 双指针 | O(n) | O(1) | 左右指针向中间收缩 |

## 双指针法的关键点

### 1. 适用条件
- 数组必须是有序的（升序或降序）
- 需要寻找满足某种关系的两个或多个元素

### 2. 指针移动策略
- **和大于目标值**：移动右指针向左（选择更小的数）
- **和小于目标值**：移动左指针向右（选择更大的数）
- **和等于目标值**：记录答案，并根据需要继续寻找

### 3. 去重处理
- 在三数之和中，需要跳过重复元素避免重复答案
- 可以在找到答案后，跳过所有相同的元素

### 4. 剪枝优化
- 利用已排序的性质，提前判断不可能的情况
- 减少不必要的计算，提高效率

## 常见变种题目

1. **四数之和**：固定两个数，使用双指针寻找另外两个数
2. **最接近的三数之和**：记录最接近目标值的和
3. **三数之和小于目标值的个数**：统计满足条件的三元组数量
4. **两数之和（无序数组）**：使用哈希表存储已遍历的元素

## 总结

双指针法是解决有序数组中寻找满足条件元素组合的有效方法：

1. **排序是前提**：确保数组有序，才能使用双指针
2. **指针移动是关键**：根据当前结果调整指针方向
3. **去重要注意**：避免重复计算相同元素
4. **剪枝能优化**：利用边界条件提前终止不可能的情况
5. **时间复杂度优秀**：通常能达到 O(n) 或 O(n²)
