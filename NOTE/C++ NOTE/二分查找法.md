# 二分查找法

## 题目一：在排序数组中查找元素的第一个和最后一个位置

### 问题描述

给你一个按照非递减顺序排列的整数数组 `nums`，和一个目标值 `target`。请你找出给定目标值在数组中的开始位置和结束位置。

如果数组中不存在目标值 `target`，返回 `[-1, -1]`。

### 算法思路

使用 **开区间二分查找** 的方法，通过 `lower_bound` 函数找到第一个大于等于 `target` 的位置，然后再找到第一个大于 `target` 的位置减一，即可得到目标值的范围。

#### 核心思想
- 使用开区间 `(left, right)` 进行二分查找
- `lower_bound` 返回最小的满足 `nums[i] >= target` 的下标 `i`
- 如果数组为空，或者所有数都 `< target`，则返回 `nums.size()`

#### 循环不变量
- `nums[left] < target`
- `nums[right] >= target`

### 代码实现

```cpp
class Solution {
    // lower_bound 返回最小的满足 nums[i] >= target 的下标 i
    // 如果数组为空，或者所有数都 < target，则返回 nums.size()
    // 要求 nums 是非递减的，即 nums[i] <= nums[i + 1]
    int lower_bound(vector<int>& nums, int target) {
        int left = -1, right = nums.size(); // 开区间 (left, right)
        while (left + 1 < right) { // 区间不为空
            // 循环不变量：
            // nums[left] < target
            // nums[right] >= target
            int mid = left + (right - left) / 2;
            if (nums[mid] >= target) {
                right = mid; // 范围缩小到 (left, mid)
            } else {
                left = mid; // 范围缩小到 (mid, right)
            }
        }
        // 循环结束后 left+1 = right
        // 此时 nums[left] < target 而 nums[right] >= target
        // 所以 right 就是第一个 >= target 的元素下标
        return right;
    }

public:
    vector<int> searchRange(vector<int>& nums, int target) {
        int start = lower_bound(nums, target);
        if (start == nums.size() || nums[start] != target) {
            return {-1, -1}; // nums 中没有 target
        }
        // 如果 start 存在，那么 end 必定存在
        int end = lower_bound(nums, target + 1) - 1;
        return {start, end};
    }
};
```

### 复杂度分析

- **时间复杂度**：O(log n)，其中 n 是数组的长度。我们使用了两次二分查找，每次都是 O(log n)。
- **空间复杂度**：O(1)，只使用了常数级别的额外空间。

## 题目二：寻找峰值

### 问题描述

峰值元素是指其值严格大于左右相邻值的元素。

给你一个整数数组 `nums`，找到峰值元素并返回其索引。数组可能包含多个峰值，在这种情况下，返回 **任何一个峰值** 所在位置即可。

你可以假设 `nums[-1] = nums[n] = -∞`。

### 算法思路

使用 **开区间二分查找** 的方法，利用峰值元素的性质来缩小搜索范围。

#### 核心思想
- 如果 `nums[mid] <= nums[mid + 1]`，说明峰值在 `mid` 的右边（因为右边有更大的元素）
- 如果 `nums[mid] > nums[mid + 1]`，说明峰值在 `mid` 的左边或就是 `mid` 本身
- 由于边界假设为 `-∞`，所以一定存在峰值

#### 开区间选择
- 使用开区间 `(-1, n-1)`，其中 `n` 是数组长度
- 为什么右边界是 `n-1` 而不是 `n`：如果有且仅有一个峰值，且其下标是 `n-1`，那么一定有 `nums[0] < nums[1] < nums[2] < ... < nums[n-1]`，这意味着每次二分更新的都是 `left`，最终答案自然就是 `n-1`
### 代码实现

```cpp
class Solution {
public:
    int findPeakElement(vector<int>& nums) {
        int left = -1, right = nums.size() - 1; // 开区间 (-1, n-1)
        
        while (left + 1 < right) { // 开区间不为空
            int mid = left + (right - left) / 2;
            if (nums[mid] <= nums[mid + 1]) { // 峰顶位置在 mid 右边
                left = mid;
            } else {
                right = mid;
            }
        }
        return right;
    }
};
```

### 复杂度分析

- **时间复杂度**：O(log n)，其中 n 是数组的长度。每次迭代都将搜索范围减半。
- **空间复杂度**：O(1)，只使用了常数级别的额外空间。

## 题目三：搜索旋转排序数组

### 问题描述

**力扣原题：33. 搜索旋转排序数组**

整数数组 `nums` 按升序排列，数组中的值 **互不相同**。

在传递给函数之前，`nums` 在预先未知的某个下标 `k`（`0 <= k < nums.length`）上进行了 **旋转**，使数组变为 `[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]`（下标 **从 0 开始** 计数）。

例如，`[0,1,2,4,5,6,7]` 在下标 `3` 处经旋转后可能变为 `[4,5,6,7,0,1,2]`。

给你 **旋转后** 的数组 `nums` 和一个整数 `target`，如果 `nums` 中存在这个目标值 `target`，则返回它的下标，否则返回 `-1`。

### 算法思路

旋转后的数组可以分为两段：第一段的所有元素都大于第二段的所有元素。我们可以利用这个性质进行二分查找。

#### 核心思想
- 使用 `last = nums.back()` 作为分界点
- 通过比较 `nums[mid]` 和 `last` 来判断 `mid` 在哪一段
- 通过比较 `target` 和 `last` 来判断 `target` 在哪一段
- 如果 `mid` 和 `target` 在不同段，则调整搜索方向
- 如果 `mid` 和 `target` 在同一段，则按普通的二分查找进行

#### 判断逻辑
1. `target > last && x <= last`：`target` 在第一段，`x` 在第二段 → 去 `mid` 左边找
2. `x > last && target <= last`：`x` 在第一段，`target` 在第二段 → 去 `mid` 右边找
3. `x >= target`：`x` 和 `target` 在同一段，按普通二分查找 → 去 `mid` 左边找
4. `x < target`：`x` 和 `target` 在同一段，按普通二分查找 → 去 `mid` 右边找
### 代码实现

```cpp
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int last = nums.back();
        int left = -1, right = nums.size() - 1; // 开区间 (-1, n-1)
        
        while (left + 1 < right) { // 开区间不为空
            int mid = left + (right - left) / 2;
            int x = nums[mid];
            
            if (target > last && x <= last) { // target 在第一段，x 在第二段
                right = mid; // 下轮循环去左边找
            } else if (x > last && target <= last) { // x 在第一段，target 在第二段
                left = mid; // 下轮循环去右边找
            } else if (x >= target) { // x 和 target 在同一段，按普通二分查找
                right = mid;
            } else {
                left = mid;
            }
        }
        return nums[right] == target ? right : -1;
    }
};
```

## 三种方法的对比

| 题目 | 方法 | 时间复杂度 | 空间复杂度 | 关键技巧 |
|------|------|------------|------------|----------|
| 查找元素范围 | 开区间二分 | O(log n) | O(1) | lower_bound 函数，两次二分查找 |
| 寻找峰值 | 开区间二分 | O(log n) | O(1) | 利用单调性判断峰值方向 |
| 旋转数组搜索 | 开区间二分 | O(log n) | O(1) | 利用分界点判断元素所在段 |

## 开区间二分查找的关键点

### 1. 区间定义
- 使用开区间 `(left, right)`，其中 `left = -1`，`right = n` 或 `n-1`
- 循环条件：`left + 1 < right`（区间不为空）
- 循环结束后：`left + 1 = right`

### 2. 中点计算
- `int mid = left + (right - left) / 2;`
- 避免整数溢出，同时保证 `mid` 偏向 `left`

### 3. 循环不变量
- 根据具体问题维护不变量
- 确保每次迭代后不变量仍然成立
- 循环结束后根据不变量得出答案

### 4. 边界处理
- 注意数组为空的情况
- 注意目标值不存在的情况
- 注意旋转数组的特殊情况

## 常见错误和注意事项

1. **区间选择错误**：混淆开区间和闭区间
2. **循环条件错误**：导致死循环或提前退出
3. **中点计算错误**：使用 `(left + right) / 2` 可能导致溢出
4. **边界条件处理不当**：忘记检查数组为空或目标不存在的情况
5. **更新方向错误**：没有正确理解题意，导致搜索方向错误

## 总结

开区间二分查找是一种简洁而强大的算法思想，通过维护循环不变量，可以优雅地解决各种二分查找问题。关键在于：

1. **正确定义区间**：根据问题特点选择合适的开区间
2. **维护循环不变量**：确保每次迭代后不变量仍然成立
3. **正确更新边界**：根据比较结果选择正确的更新方向
4. **处理边界情况**：考虑各种特殊情况，确保算法的鲁棒性
