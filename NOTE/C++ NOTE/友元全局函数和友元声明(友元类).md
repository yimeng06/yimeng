# 友元 (friend) —— 给特定的人开后门

**一句话**：正常情况下private是"闲人免进"，但`friend`可以给指定的人发一张**VIP通行证**。

> 友元关系是**单向的**：A说B是朋友，不代表B把A当朋友。而且**不可继承**。

---

## 三种友元写法

### 1. 友元全局函数 —— "这个外人我认"

```cpp
class Point {
private:
    double x, y;

public:
    Point(double x = 0, double y = 0) : x(x), y(y) {}   // 构造函数（初始化列表）

    // 发VIP卡给这两个全局函数
    friend double distance(const Point& p1, const Point& p2);
    friend void printPoint(const Point& p);
};

// 虽然不是成员函数，但能直接访问私有x和y！
double distance(const Point& p1, const Point& p2) {
    double dx = p1.x - p2.x;    // ✅ 正常情况下这行会报错
    double dy = p1.y - p2.y;
    return sqrt(dx*dx + dy*dy);
}

void printPoint(const Point& p) {
    cout << "(" << p.x << ", " << p.y << ")";   // ✅ 也能访问
}
```

### 2. 友元类 —— "这一家人我都认"

```cpp
class Phone {
private:
    int price;              // 私有财产

public:
    Phone(int p) : price(p) {}
    friend class myphone;   // myphone全家都能进我的private！
};

class myphone {
public:
    void showPrice(Phone& p) {
        cout << p.price;    // ✅ 后门进来的，随便看
    }
};
```

### 3. 友元成员函数 —— "只认你家的某个人"

```cpp
class A {
private:
    int secret;

public:
    friend void B::showSecret(A& a);   // 只给B类的showSecret开后门
};
```

## 附带知识点：构造函数初始化列表

上面代码里出现的语法：

```cpp
Point(double x = 0, double y = 0) : x(x), y(y) {}
//  ↑参数列表(带默认值)     ↑初始化列表    ↑函数体(空的)
```

| 部分 | 含义 |
|:-----|:-----|
| `double x = 0` | 参数默认值，不传就用0 |
| `: x(x), y(y)` | **初始化列表**，等价于 `this->x=x; this->y=y;` 但更高效 |
| `{}` | 函数体，这里为空因为初始化已经完成了 |

> 初始化列表 vs 函数体内赋值：内置类型差别不大，但类类型成员用初始化列表**只构造一次**，函数体内赋值会**先默认构造再赋值**（多一次操作）。能用初始化列表就用它！

---

## 总结

| 友元类型 | 语法 | 谁获得了权限 |
|:---------|:-----|:------------|
| **友元全局函数** | `friend void func();` | 某个外部函数 |
| **友元类** | `friend class B;` | B类的所有成员函数 |
| **友元成员函数** | `friend void B::func();` | B类的某个特定函数 |

**使用场景**：运算符重载（如`<<`、`+`）最常用到友元——需要访问私有成员但又不想写成成员函数。
