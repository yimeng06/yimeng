# C++ 面向对象五大特征

| 特征 | 一句话 | 生活中的例子 |
|:-----:|:-------|:------------|
| **类** | 设计图纸 | "汽车图纸" |
| **对象** | 按图纸造出来的实物 | "我家那辆红色比亚迪" |
| **封装** | 把内部藏起来，只暴露简单接口 | 发动机盖起来，只给你刹车和油门——你开车不用懂发动机 |
| **继承** | 子类拿走父类的全部家当，再加自己的 | "电动汽车"继承了"汽车"的所有东西，还加了充电功能 |
| **多态** | 同一个指令，不同对象有不同反应 | 对狗说"叫"→"汪汪"；对猫说"叫"→"喵喵" |

> **口诀**：类是图纸造对象，封装隐藏内部妙，子承父业叫继承，同令不同效是多态。
