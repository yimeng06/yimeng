# 子集（二进制枚举）

**题目**：给定数组，返回所有可能的子集。

```
输入: [1,2,3]
输出: [[], [1], [2], [1,2], [3], [1,3], [2,3], [1,2,3]]
// 共 2³ = 8 个子集
```

## 核心思想：二进制 —— 每个元素只有两种命运（选 or 不选）

n个元素 → 每位代表一个元素的**选/不选** → 一共 `2^n` 种组合

```
i的二进制    选了哪些        子集
───────────────────────────────
  000       谁都不选         []
  001       选第0个          [1]
  010       选第1个          [2]
  011       选第0,1个        [1,2]
  100       选第2个          [3]
  101       选第0,2个        [1,3]
  110       选第1,2个        [2,3]
  111       全选             [1,2,3]
     ↑
   第j位=1就选nums[j]，=0就跳过
```

## 代码

```cpp
vector<vector<int>> subsets(vector<int>& nums) {
    int n = nums.size();
    vector<vector<int>> ans(1 << n);         // 2^n个子集

    for (int i = 0; i < (1 << n); i++) {     // 枚举每种选法
        for (int j = 0; j < n; j++) {        // 检查每一位
            if ((i >> j) & 1)                // 第j位是1？
                ans[i].push_back(nums[j]);   // 选上！
        }
    }
    return ans;
}
```

**就三行核心逻辑**：
1. `(1 << n)` → 总共有多少种选法（2的n次方）
2. `(i >> j) & 1` → 第j位是1吗？（把第j位移到最末尾，&1判断）
3. 是1就把`nums[j]`塞进去

---

## 总结

| 要点 | 说明 |
|:-----|:-----|
| **时间复杂度** | O(n × 2^n)，每种选法都要扫一遍n位 |
| **空间复杂度** | O(2^n)（存所有子集）|
| **适用条件** | n ≤ 20左右（再大就爆了）|
| **本质** | 二进制枚举 = 用数字的每一位表示"选/不选" |

> **口诀**：n个元素选或不选，就是n位二进制，从0枚举到 `2^n - 1`，每位是1就收。
