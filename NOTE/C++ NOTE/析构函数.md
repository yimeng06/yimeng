# 析构函数 (~)

**一句话**：对象死的时候自动调用的"临终遗言"，专门用来收拾 `new` 的烂摊子。

## 语法

```cpp
~类名() {
    // 清理资源：delete、关闭文件等
}
```

`~` 就是"取反/否定"的意思——构造函数创建对象，析构函数销毁它。

## 典型用法（配对 new/delete）

```cpp
class Person {
public:
    char* name;

    Person(const char* name) {
        this->name = new char[strlen(name) + 1];   // 构造时申请内存
        strcpy(this->name, name);
    }

    ~Person() {                     // 析构时释放！
        if (name != nullptr) {
            delete[] name;          // 把new的还回去
            name = nullptr;         // 防止悬空指针（野指针）
        }
    }
};
```

## 关键点

| 要点 | 说明 |
|:-----|:-----|
| **自动调用** | 不用手动调用，对象销毁时自动触发 |
| **配对使用** | 有 `new` 就得有 `delete`，在析构里写最稳妥 |
| **只能有一个** | 不支持重载，不能带参数 |
| **调用时机** | 局部变量离开作用域 / `delete` 对象时 |
| **nullptr** | 释放后置空，防止指针还在那瞎指 |
