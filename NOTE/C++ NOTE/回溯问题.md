# 回溯问题

## 题目一：电话号码的字母组合

### 问题描述

**力扣原题：17. 电话号码的字母组合**

给定一个仅包含数字 `2-9` 的字符串，返回所有它能表示的字母组合。答案可以按 **任意顺序** 返回。

给出数字到字母的映射如下（与电话按键相同）。注意 1 不对应任何字母。

```
2: abc    3: def    4: ghi    5: jkl
6: mno    7: pqrs   8: tuv    9: wxyz
```

**示例**：
- 输入：`digits = "23"`
- 输出：`["ad","ae","af","bd","be","bf","cd","ce","cf"]`

### 算法思路

使用 **回溯算法（深度优先搜索）** 来解决这个问题。

#### 核心思想
1. **数字到字母的映射**：使用数组存储每个数字对应的字母
2. **递归搜索**：对于每个数字，尝试所有可能的字母
3. **回溯**：递归返回后，撤销当前选择，尝试下一个字母
4. **收集结果**：当处理完所有数字时，将当前组合加入结果集

#### 递归函数 `dfs(i)` 的含义

`dfs(i)` 处理的是从下标 `i` 到末尾的所有字母组合。`dfs(i)` 不仅仅在枚举 `i`，还包含了 `dfs(i+1)`, `dfs(i+2)`, …, `dfs(n)` 这之后的所有递归调用。

**重要说明**：
- 单纯说「枚举 i」是不准确的，因为除了枚举 i，还要递归处理剩余部分
- 正因如此，应该理解为处理「从 i 开始到末尾」的所有组合
- 递归的深度等于数字字符串的长度

#### 算法流程

```
1. 创建数字到字母的映射数组
2. 初始化结果集和路径字符串
3. 从第0个位置开始递归：
   a. 如果当前位置等于字符串长度，说明组合完成，加入结果集
   b. 否则，遍历当前数字对应的所有字母
   c. 将字母放入路径的当前位置
   d. 递归处理下一个位置
   e. （回溯）自动撤销当前选择，尝试下一个字母
4. 返回结果集
```

### 代码实现

```cpp
class Solution {
    static constexpr string MAPPING[10] = {"", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};

public:
    vector<string> letterCombinations(string digits) {
        int n = digits.length();
        if (n == 0) {
            return {};
        }

        vector<string> ans;
        string path(n, 0);  // 创建长度为n的字符串，初始值为0（空字符）
        // 注意 path 长度一开始就是 n，不是空串

        // lambda 递归
        auto dfs = [&](this auto&& dfs, int i) -> void {
            if (i == n) {
                ans.emplace_back(path);  // 将完整组合加入结果集
                return;
            }
            for (char c : MAPPING[digits[i] - '0']) {
                path[i] = c;  // 直接覆盖：直接修改第i个位置的字符
                dfs(i + 1);
            }
        };

        dfs(0);  // 启动回溯递归
        return ans;
    }
};
```

### 代码解析

#### 1. 数字到字母的映射

```cpp
static constexpr string MAPPING[10] = {"", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};
```

- 使用静态常量数组存储映射关系
- `MAPPING[0]` 和 `MAPPING[1]` 为空字符串，因为数字 0 和 1 不对应任何字母
- `MAPPING[2]` = "abc"，`MAPPING[3]` = "def"，以此类推

#### 2. 路径字符串的初始化

```cpp
string path(n, 0);  // 创建长度为n的字符串，初始值为0（空字符）
```

- 提前分配好足够的空间，避免频繁的字符串拼接
- 初始值为空字符 `\0`
- 通过 `path[i] = c` 直接修改第 i 个位置的字符

#### 3. Lambda 递归函数

```cpp
auto dfs = [&](this auto&& dfs, int i) -> void {
    // 递归逻辑
};
```

- 使用 C++23 的 `this auto&&` 语法实现 lambda 递归
- 参数 `i` 表示当前处理的位置
- 返回类型为 `void`

#### 4. 递归终止条件

```cpp
if (i == n) {
    ans.emplace_back(path);
    return;
}
```

- 当 `i == n` 时，说明已经处理完所有数字
- 将当前组合加入结果集
- 返回上一层递归

#### 5. 递归过程

```cpp
for (char c : MAPPING[digits[i] - '0']) {
    path[i] = c;
    dfs(i + 1);
}
```

- 遍历当前数字对应的所有字母
- 将字母放入路径的当前位置
- 递归处理下一个位置
- （回溯）循环结束后，自动撤销当前选择

### 复杂度分析

#### 时间复杂度

- **最坏情况**：O(4^n)，其中 n 是数字字符串的长度
- **分析**：每个数字最多对应 4 个字母（数字 7 和 9），所以最多有 4^n 种组合
- **实际时间**：取决于具体输入，平均为 O(3^n × n)

#### 空间复杂度

- **递归栈空间**：O(n)，递归深度最大为 n
- **结果集空间**：O(4^n × n)，存储所有可能的组合
- **路径空间**：O(n)，存储当前组合
- **总空间复杂度**：O(4^n × n)

### push_back vs emplace_back

```cpp
ans.push_back(path);     // 拷贝构造：先创建临时对象，再拷贝
ans.emplace_back(path);  // 直接构造：在容器内直接构造对象
```

#### 区别

| 特性 | push_back | emplace_back |
|------|-----------|--------------|
| 构造方式 | 拷贝构造 | 直接构造 |
| 性能 | 较低（多一次拷贝） | 较高（避免拷贝） |
| 适用场景 | 通用 | 构造复杂对象时更高效 |

#### 推荐使用

```cpp
// ✅ 推荐：使用 emplace_back
ans.emplace_back(path);

// ❌ 不推荐：使用 push_back（性能稍差）
ans.push_back(path);
```

**注意**：对于简单类型（如 `int`），两者性能差异不大；但对于复杂类型（如 `string`、自定义类），`emplace_back` 更高效。

### 关键点总结

1. **提前分配空间**：`string path(n, 0)` 提前分配好空间，避免频繁的字符串拼接
2. **直接修改字符**：`path[i] = c` 直接修改第 i 个位置的字符，而不是拼接
3. **Lambda 递归**：使用 C++23 的 `this auto&&` 语法实现 lambda 递归
4. **回溯自动撤销**：循环结束后，自动撤销当前选择，不需要显式回溯
5. **使用 emplace_back**：比 `push_back` 更高效，避免不必要的拷贝

## 回溯算法的核心思想

### 什么是回溯算法？

回溯算法是一种通过穷举所有可能情况来寻找问题解决方案的算法。它的基本思想是：

1. **深度优先搜索**：沿着一条路径一直走下去，直到无法继续
2. **回溯撤销**：当无法继续时，返回上一层，尝试其他路径
3. **剪枝优化**：在搜索过程中，提前终止不可能的路径

### 回溯算法的模板

```cpp
void backtrack(参数) {
    if (终止条件) {
        收集结果;
        return;
    }
    
    for (选择：本层集合中元素（树中节点孩子的数量就是集合的大小）) {
        处理节点;
        backtrack(路径，选择列表);  // 递归
        回溯，撤销处理结果;
    }
}
```

### 回溯算法的适用场景

1. **组合问题**：从 n 个元素中选取 k 个元素的组合
2. **排列问题**：n 个元素的全排列
3. **子集问题**：求所有子集
4. **切割问题**：字符串的切割方式
5. **棋盘问题**：N皇后、数独等
6. **其他搜索问题**：路径搜索、约束满足等

### 回溯算法的时间复杂度

回溯算法的时间复杂度通常是指数级的，因为需要穷举所有可能的情况。

- **组合问题**：O(C(n,k)) = O(n! / (k! * (n-k)!))
- **排列问题**：O(n!)
- **子集问题**：O(2^n)
- **切割问题**：O(2^n)

### 回溯算法的优化技巧

1. **剪枝**：提前终止不可能的路径
2. **排序**：先排序，便于剪枝和去重
3. **去重**：使用 `used` 数组或排序后跳过重复元素
4. **记忆化**：缓存中间结果，避免重复计算
5. **迭代加深**：限制搜索深度，逐步增加

### 回溯算法 vs 深度优先搜索

| 特性 | 回溯算法 | 深度优先搜索 |
|------|----------|--------------|
| 目标 | 寻找所有解 | 遍历所有节点 |
| 回溯 | 显式回溯 | 自动回溯 |
| 剪枝 | 常用 | 较少使用 |
| 应用 | 组合、排列、子集等 | 图遍历、路径搜索等 |

## 总结

回溯算法是解决组合、排列、子集等问题的有效方法。

**关键要点**：
1. **理解递归含义**：`dfs(i)` 处理的是从下标 i 到末尾的所有组合
2. **提前分配空间**：避免频繁的字符串拼接和数组扩容
3. **直接修改元素**：通过索引直接修改，而不是拼接
4. **回溯自动撤销**：循环结束后自动撤销，不需要显式回溯
5. **使用 emplace_back**：比 `push_back` 更高效

- 使用 `emplace_back` 提高性能
