# C++ 引用 (&)

**一句话**：引用就是给变量起个"外号"，叫哪个都指同一个东西。

---

## 一、基本语法

```cpp
int a = 10;
int& ref = a;    // ref是a的别名，不是拷贝

ref = 20;        // 改ref = 改a，因为它们是同一个东西
cout << a;       // 输出 20
```

> 引用**必须初始化**，一旦绑定就不能换人（跟指针不一样）

---

## 二、类中的引用成员变量

引用做成员变量有点特殊——**必须在初始化列表里给它找个主人**

```cpp
class Example {
private:
    int& ref;        // 引用成员：必须绑定一个实体

public:
    Example(int& ex) : ref(ex) { }   // 初始化列表里绑定！不能在构造函数体里搞
};
```

为什么？因为引用**不存在"空着"的状态**——生下来就得有主。

```cpp
int main() {
    int value = 42;
    Example obj(value);   // ref → value（绑定了）
    // 现在ref和value是一根绳上的蚂蚱，改谁都影响对方
}
```

**共享效果**：`ref` 和 `value` 是同一个变量的两个名字，牵一发而动全身。

---

## 三、const 引用 —— 只读外号

```cpp
const int& cref = a;   // "我只能看，不能摸"

// cref = 10;           ❌ 编译错误：不许改！
cout << cref;          // ✅ 读是可以的
```

**两大限制**：
1. 不能重新绑定别人（引用本来就不行）
2. 通过它不能修改原值（const的功劳）

---

## 四、双 const —— 最严格的锁

`const` 出现两次，各管各的：

```cpp
class Widget {
private:
    int importantValue;

public:
    // 返回值const + 函数const = 双重保险
    const int& getValue() const {
        return importantValue;
        // ↑返回值const：外面拿到手也不能改
        //     函数const：里面也不能改成员变量
    }

    // 对比：非const版本 —— 外面可以随便改
    int& getValue() {
        return importantValue;   // 拿到的是"写权限"
    }
};
```

| 写法 | 能读？ | 能通过引用改值？ | 函数内能改成员？ |
|:----:|:------:|:----------------:|:--------------:|
| `int& get()` | ✅ | ✅ | ✅ |
| `const int& get() const` | ✅ | ❌ | ❌ |

---

## 总结

| 知识点 | 一句话 |
|:-------|:-------|
| **普通引用** | 起别名，改谁都一样 |
| **引用成员变量** | 必须在初始化列表里"认主" |
| **const引用** | 只能看，不能摸 |
| **双const** | 内外都冻结，纯只读模式 |

**引用 vs 指针**：
- 引用：一生只爱一个人（绑定后不能换）
- 指针：花心大萝卜（随时可以指向别人）
- 引用：不能用null；指针可以
