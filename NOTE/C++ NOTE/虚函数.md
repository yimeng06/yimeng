# 虚函数 (virtual)

**一句话**：让基类指针"认出"真正的对象类型，调用正确的函数版本。

---

## 没有虚函数 —— "只看脸不看人"

```cpp
class Base {
public:
    void show() { cout << "Base" << endl; }
};

class Derived : public Base {
public:
    void show() { cout << "Derived" << endl; }
};

Base* ptr = new Derived();   // 基类指针指向派生类对象
ptr->show();                 // 输出 "Base" ❌
```

虽然ptr指向的是Derived对象，但编译器**只看指针类型（Base）**，所以调的是Base的show。这叫**静态绑定**——编译时就定死了。

---

## 加上 virtual —— "看透本质"

```cpp
class Base {
public:
    virtual void show() { cout << "Base" << endl; }  // 加virtual！
};

class Derived : public Base {
public:
    void show() override { cout << "Derived" << endl; }  // override显式声明重写
};

Base* ptr = new Derived();
ptr->show();                 // 输出 "Derived" ✅
```

加了`virtual`后变成**动态绑定**——运行时根据对象的**真实类型**决定调哪个函数。ptr虽然是Base类型，但它指向的是Derived对象，所以调Derived的show。

> `override` 不是必须的，但写上能让编译器帮你检查：基类没有对应虚函数就报错。

---

## 虚析构函数 —— 防止内存泄漏

用基类指针`delete`派生类对象时，如果析构函数不是虚的，**派生类的析构不会被调用**！

```cpp
class Base {
public:
    virtual ~Base() { cout << "Base 死了" << endl; }   // 必须加virtual！
};

class Derived : public Base {
    ~Derived() { cout << "Derived 死了" << endl; }
};

Base* p = new Derived();
delete p;
// 输出：
// Derived 死了     ← 先死儿子
// Base 死了        ← 再死爹
```

析构顺序永远是：**先子后父**（和构造相反）。

如果`~Base()`不加virtual？直接跳过`~Derived()`，派生类的资源没人释放 → **内存泄漏**。

---

## 总结

| 关键字 | 作用 | 什么时候用 |
|:-------|:-----|:-----------|
| `virtual` | 声明虚函数 | 基类中希望子类重写的函数 |
| `override` | 标记重写（可选） | 子类重写时加上，让编译器帮忙查错 |
| **虚析构** | 确保delete时先调子类析构 | **只要类可能被继承，析构函数就加virtual** |
