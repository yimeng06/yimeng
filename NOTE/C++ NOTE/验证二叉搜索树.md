# 验证二叉搜索树 (BST)

## 什么是 BST？

```
    5
   / \
  3   7     ← 左 < 根 < 右，且子树也是BST
 / \   \
1   4   9
```

**规则**：左子树全部 < 根 < 右子树全部，递归成立。

> **BST的中序遍历结果一定是严格递增的！** 这是最重要的性质。

---

## 三种解法（前/中/后序遍历）

### 方法一：前序遍历 —— "给你一个范围，你给我待在里面"

```cpp
bool isValidBST(TreeNode* root,
                long long left = LLONG_MIN,
                long long right = LLONG_MAX) {
    if (!root) return true;

    long long x = root->val;
    // 当前节点必须在(left, right)开区间内
    return left < x && x < right
        && isValidBST(root->left, left, x)      // 左边：上限变成我
        && isValidBST(root->right, x, right);    // 右边：下限变成我
}
```

**思路**：根节点在(-∞, +∞)，左孩子在(-∞, root->val)，右孩子在(root->val, +∞)。越往下范围越小，谁超出范围谁就不是BST。

---

### 方法二：中序遍历 —— "中序遍历结果必须严格递增"

```cpp
class Solution {
    long long pre = LLONG_MIN;   // 上一个访问的值

public:
    bool isValidBST(TreeNode* root) {
        if (!root) return true;

        if (!isValidBST(root->left)) return false;   // 左：先搞定左子树

        if (root->val <= pre) return false;           // 中：当前必须 > 上一个

        pre = root->val;                              // 记录当前值

        return isValidBST(root->right);               // 右：再去搞右子树
    }
};
```

**核心**：中序遍历BST = 从小到大排序。只要出现 `当前值 ≤ 前一个值`，直接判死刑。

---

### 方法三：后序遍历 —— "自底向上汇报（最难）"

```cpp
class Solution {
    // 返回{子树最小值, 子树最大值}，不是BST就返回{-∞, +∞}
    pair<long long, long long> dfs(TreeNode* node) {
        if (!node) return {LLONG_MAX, LLONG_MIN};    // 空节点返回极端值

        auto [l_min, l_max] = dfs(node->left);       // 结构化绑定，拆分返回值
        auto [r_min, r_max] = dfs(node->right);

        long long x = node->val;

        if (x <= l_max || x >= r_min)                 // 我 ≤ 左最大 或 我 ≥ 右最小 → 不合法
            return {LLONG_MIN, LLONG_MAX};            // 返回"烂标记"

        return {min(l_min, x), max(r_max, x)};        // 汇报：子树的[最小, 最大]
    }

public:
    bool isValidBST(TreeNode* root) {
        return dfs(root).second != LLONG_MAX;          // 没被标烂就是真BST
    }
};
```

**两个C++知识点**：

| 语法 | 说明 | 示例 |
|:-----|:-----|:-----|
| `pair<T,T>` | 函数返回两个值的盒子 | `return {3, 7}` |
| `auto [a,b]` | 结构化绑定，把pair拆成两个变量 | `auto [mi,mx] = dfs(node)` |

**思路**：每个节点向父节点汇报"我这棵子树的范围[min,max]"，父节点检查自己是否在这个范围内。从叶子开始往上验证。

---

## 总结

| 方法 | 遍历方式 | 思路 | 难度 |
|:-----|:---------|:-----|:-----|
| **前序** | 根→左→右 | 给每个节点限定取值范围 | ⭐ |
| **中序** | 左→根→右 | 中序结果必须严格递增 | ⭐⭐ 推荐 |
| **后序** | 左→右→根 | 自底向上汇报范围 | ⭐⭐⭐ |

**面试推荐方法二（中序）**——代码最直观，也最好讲清楚。
