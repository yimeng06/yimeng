# 二维布尔数组

## 基本概念

二维布尔数组是一个由布尔值组成的二维数据结构，在C++中通常使用 `vector<vector<bool>>` 来实现。

## 创建方式

### 标准创建方法

```cpp
vector<vector<bool>> dp(m, vector<bool>(n, false));
```

**创建一个 m 行 n 列的二维布尔数组，初始值均为 false**

### 创建过程解析

#### 最内层：`vector<bool>(n, false)`
创建一个一维 vector：
1. 包含 `n` 个元素
2. 每个元素都是 `bool` 类型
3. 全部初始化为 `false`

#### 外层：`vector<vector<bool>> dp(m, ...)`
创建一个二维 vector（vector 的 vector）：
1. 包含 `m` 个元素
2. 每个元素都是我们第一步创建的 `vector<bool>(n, false)`
3. 所以得到 `m × n` 的二维数组

### 具体示例

如果 `m = 3, n = 4`：

```cpp
vector<vector<bool>> dp(3, vector<bool>(4, false));
```

创建的数组结构：
```cpp
dp = {
    {false, false, false, false},  // 第0行
    {false, false, false, false},  // 第1行  
    {false, false, false, false}   // 第2行
};
```

## 访问和修改

### 基本访问方式

```cpp
dp[i][j] = true;           // 设置第i行第j列为true
bool value = dp[1][2];     // 获取第1行第2列的值
```

### 遍历二维布尔数组

#### 使用下标遍历

```cpp
for (int i = 0; i < m; i++) {
    for (int j = 0; j < n; j++) {
        cout << dp[i][j] << " ";
    }
    cout << endl;
}
```

#### 使用范围for循环（C++11）

```cpp
for (const auto& row : dp) {
    for (bool val : row) {
        cout << val << " ";
    }
    cout << endl;
}
```

## 常用操作

### 初始化为特定值

```cpp
// 全部初始化为 true
vector<vector<bool>> dp(m, vector<bool>(n, true));

// 使用lambda函数初始化
vector<vector<bool>> dp(m, vector<bool>(n));
for (int i = 0; i < m; i++) {
    for (int j = 0; j < n; j++) {
        dp[i][j] = (i + j) % 2 == 0;  // 根据条件初始化
    }
}
```

### 获取数组大小

```cpp
int rows = dp.size();        // 行数
int cols = dp[0].size();     // 列数（假设至少有一行）
```

### 检查是否为空

```cpp
if (dp.empty()) {
    cout << "数组为空" << endl;
}
```

## 实际应用场景

### 1. 动态规划中的状态记录

```cpp
// 0-1背包问题：记录哪些物品被选中
vector<vector<bool>> selected(n + 1, vector<bool>(capacity + 1, false));
```

### 2. 图的邻接矩阵

```cpp
// 表示无向图的邻接矩阵
vector<vector<bool>> adj_matrix(n, vector<bool>(n, false));
adj_matrix[0][1] = true;  // 0和1之间有边
adj_matrix[1][0] = true;  // 无向图，边是双向的
```

### 3. 迷宫问题中的访问标记

```cpp
// 标记迷宫中的格子是否被访问过
vector<vector<bool>> visited(rows, vector<bool>(cols, false));

void dfs(int x, int y) {
    if (visited[x][y]) return;  // 已经访问过
    visited[x][y] = true;       // 标记为已访问
    // ... 继续搜索
}
```

### 4. 子集和问题

```cpp
// 判断是否可以组成特定的和
vector<vector<bool>> dp(n + 1, vector<bool>(target + 1, false));
dp[0][0] = true;  // 空集合可以组成和为0
```

## 注意事项

### 1. `vector<bool>` 的特殊性

`vector<bool>` 是一个特化的模板类，它不是真正的容器，而是使用位压缩来节省空间：
- **优点**：节省内存，每个bool只占1bit
- **缺点**：不能获取元素的引用，只能获取值

```cpp
// 错误：不能获取bool的引用
// bool& ref = dp[0][0];  // 编译错误

// 正确：只能获取值
bool val = dp[0][0];
```

### 2. 如果需要引用，使用其他类型

```cpp
// 使用vector<char>代替vector<bool>
vector<vector<char>> dp(m, vector<char>(n, 0));
char& ref = dp[0][0];  // 可以获取引用
```

### 3. 边界检查

```cpp
// 访问前检查边界
if (i >= 0 && i < dp.size() && j >= 0 && j < dp[0].size()) {
    dp[i][j] = true;
}
```

### 4. 内存考虑

对于大型二维数组，`vector<bool>` 可以显著节省内存：
- `vector<bool>`：每个元素占1bit
- `vector<char>`：每个元素占1byte（8bit）
- `vector<int>`：每个元素占4byte（32bit）

## 性能对比

| 操作 | vector<bool> | vector<char> | vector<int> |
|------|--------------|--------------|------------|
| 内存占用 | 最低 | 中等 | 较高 |
| 访问速度 | 稍慢 | 快 | 快 |
| 支持引用 | ❌ | ✅ | ✅ |
| 适用场景 | 大型状态数组 | 一般情况 | 需要存储更多信息 |

## 总结

二维布尔数组是C++中常用的数据结构，特别适合用于：

1. **动态规划**：记录状态和转移
2. **图论**：表示邻接矩阵
3. **搜索算法**：标记访问状态
4. **组合问题**：记录子集信息

**关键要点**：
- 使用 `vector<vector<bool>>` 创建二维布尔数组
- 注意 `vector<bool>` 的特殊性，不能获取引用
- 合理使用可以节省大量内存
- 访问时注意边界检查
