# new 运算符 —— 堆内存的"申请单"

**一句话**：在堆（heap）上申请内存，用完必须手动 `delete` 还回去，否则**内存泄漏**。

## 基本语法

```cpp
int* p = new int;          // 单个变量
int* arr = new int[100];   // 数组
string* s = new string("hello");  // 带初始化

// 用完记得还！
delete p;
delete[] arr;              // 数组用 delete[]，不是 delete！
delete s;
```

> **`new` 和 `delete` 必须配对**，有借有还，再借不难。忘了还？内存泄漏。还两次？崩溃。

---

## 二维数组的两种创建方式

### 方式一：非连续分配（每行独立申请）

```cpp
int n = 3, m = 4;
int** ptr = new int*[n];           // 先申请n个行指针

for (int i = 0; i < n; i++) {
    ptr[i] = new int[m];            // 每行单独申请m个元素
}

// 使用和普通二维数组一样
ptr[0][0] = 1;
ptr[2][3] = 99;

// 释放也要两层！
for (int i = 0; i < n; i++)
    delete[] ptr[i];                // 先释放每行
delete[] ptr;                       // 再释放行指针数组
```

**内存布局**：每行在堆的不同位置，像散落的积木。
```
ptr[0] → ┌───┬───┬───┬───┐     （堆的某处）
ptr[1] → ┌───┬───┬───┬───┐     （堆的另一处）
ptr[2] → ┌───┬───┬───┬───┐     （堆的又一处）
```

### 方式二：连续分配（一次性申请一大块）

```cpp
int n = 3, m = 4;

int* data = new int[n * m];        // 一次性申请所有空间（连续！）
int** ptr = new int*[n];

for (int i = 0; i < n; i++) {
    ptr[i] = &data[i * m];         // 行指针指向大块的对应位置
}
```

**内存布局**：所有数据挤在一起，缓存更友好。
```
data → │0,0│0,1│0,2│0,3│1,0│1,1│1,2│1,3│2,0│2,1│2,2│2,3│
ptr[0] ───────────────↑
ptr[1] ───────────────────────────────↑
ptr[2] ───────────────────────────────────────────────↑
```

| | 非连续 | 连续 |
|:-:|:-------|:-----|
| **写法** | 每行单独new | 一次new整块 |
| **内存** | 分散在各处 | 一整块连续 |
| **缓存友好度** | 一般 | **更好**（CPU预读爽）|
| **释放** | 两层delete[] | 先删data再删ptr |

---

## 总结

| 要点 | 说明 |
|:-----|:-----|
| **配对原则** | `new` ↔ `delete`，`new[]` ↔ `delete[]` |
| **单个 vs 数组** | 单个用 `delete`，数组必须 `delete[]` |
| **二维数组** | 非连续（简单但分散）vs 连续（稍复杂但高效）|
| **最佳实践** | 能用 `vector` 就别手动 `new`——自动管理内存不香吗？|

> **现代C++建议**：优先用 `vector<vector<int>>` 代替手动 `new` 二维数组，除非你对性能有极致要求。
