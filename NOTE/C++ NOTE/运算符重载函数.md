# 运算符重载

**一句话**：让自定义类型的对象也能用 `+`、`-`、`<<` 这些运算符，像内置类型一样自然。

---

## 函数名规则（固定写法，不能乱起）

| 运算符 | 函数名 | 运算符 | 函数名 |
|:------:|:-------|:------:|:-------|
| `+` | `operator+` | `==` | `operator==` |
| `-` | `operator-` | `<<` | `operator<<` |
| `*` | `operator*` | `>>` | `operator>>` |
| `/` | `operator/` | `[]` | `operator[]` |

---

## 两种写法

### 写法一：成员函数（推荐用于单目运算符）

```cpp
class Complex {
    double real, imag;
public:
    Complex(double r, double i) : real(r), imag(i) {}

    // c1 + c2 → c1.operator+(c2)
    Complex operator+(const Complex& other) {
        return Complex(real + other.real, imag + other.imag);
    }
};

Complex c1(1, 2), c2(3, 4);
Complex c3 = c1 + c2;   // 看起来就像在加整数一样爽
```

### 写法二：友元函数（必须用于 `<<`、双目运算符左操作数不是本类时）

```cpp
class Complex {
    double real, imag;
public:
    Complex(double r, double i) : real(r), imag(i) {}

    // 友元：cout << c 才能写成 cout在左边
    friend ostream& operator<<(ostream& out, const Complex& c) {
        out << c.real << "+" << c.imag << "i";
        return out;      // 支持链式调用：cout << c1 << c2
    }
};

Complex c(3, 4);
cout << c << endl;     // 输出: 3+4i
```

> **为什么`<<`必须用友元？** 因为 `cout << c` 等价于 `cout.operator<<(c)`，但cout是`ostream`对象，不是你的类，所以只能写成全局/友元函数。

---

## 常见用法速查

```cpp
// 加法（成员函数）
Complex operator+(const Complex& o) { return {real+o.real, imag+o.imag}; }

// 输出流（友元函数）
friend ostream& operator<<(ostream& out, const Complex& c);

// 比较相等
bool operator==(const Complex& o) { return real==o.real && imag==o.imag; }

// 下标访问
int& operator[](int i) { return arr[i]; }       // 可修改
const int& operator[](int i) const { return arr[i]; }  // 只读版本

// 类型转换
operator int() const { return real; }   // Complex → int（慎用！隐式转换坑多）
```
