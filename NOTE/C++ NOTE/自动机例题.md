# 字符串转整数（自动机/状态机解法）

**题目**：`myAtoi("   -42")` → `-42`，类似C++的`atoi()`但要处理溢出。

**规则**：读前导空格 → 读符号 → 读数字 → 遇到非数字或溢出就停。

---

## 状态机思路

把整个过程看作一个**人在不同状态间跳转**：

```
  ┌───────空格────────┐
  │                    ↓
start ──+/-──→ signed ──数字──→ in_number ──其他──→ end
  │                    ↑                │
  └────数字────────────┘                │
                       ↑                │
                       └────────────────┘
```

| 当前状态 | 遇到空格 | 遇到+/- | 遇到数字 | 遇到其他 |
|:-------:|:-------:|:------:|:-------:|:------:|
| **start** | start | signed | in_number | end |
| **signed** | end | end | in_number | end |
| **in_number** | end | end | in_number | end |
| **end** | end | end | end | end |

> 到了**end状态就是垃圾时间**，无论输入什么都出不来——这就是"终止态"。

---

## 代码实现

```cpp
class Automaton {
    string state = "start";
    // 状态转移表：当前状态 + 输入类型 → 下一个状态
    unordered_map<string, vector<string>> table = {
        {"start",     {"start", "signed", "in_number", "end"}},
        {"signed",    {"end",   "end",    "in_number", "end"}},
        {"in_number", {"end",   "end",    "in_number", "end"}},
        {"end",       {"end",   "end",    "end",       "end"}}
    };

    // 判断字符属于哪一类：0=空格 1=符号 2=数字 3=其他
    int get_col(char c) {
        if (isspace(c)) return 0;
        if (c == '+' || c == '-') return 1;
        if (isdigit(c)) return 2;
        return 3;                           // 垃圾字符 → 直接送进end
    }

public:
    int sign = 1;           // 正负号
    long long ans = 0;      // 存结果（用long long防溢出）

    void get(char c) {
        state = table[state][get_col(c)];   // 第一步：查表跳转状态

        if (state == "in_number") {         // 数字状态：干活！
            ans = ans * 10 + (c - '0');     // 累加数字
            // 提前做溢出裁剪，别等越界了再后悔
            ans = sign == 1 ? min(ans, (long long)INT_MAX)
                            : min(ans, -(long long)INT_MIN);
        }
        else if (state == "signed")         // 符号状态：记正负
            sign = (c == '+') ? 1 : -1;
        // 其他状态？啥也不干，摆烂
    }
};

class Solution {
public:
    int myAtoi(string str) {
        Automaton am;
        for (char c : str)          // 一个字符一个字符地"喂"给状态机
            am.get(c);
        return am.sign * am.ans;    // 符号 × 数值 = 最终答案
    }
};
```

## 概念辨析

面试官可能会问：**自动机和状态机有啥关系？**

```
自动机（Automata）—— 大家族的族长
├── 有限状态机 FSM ← ⭐ 我们用的就是这个（编程中的"自动机"通常指它）
│   ├── DFA（确定型）—— 同一输入只有一条路可走
│   └── NFA（非确定型）—— 同一输入可能分叉
├── 下推自动机 PDA —— 多了一个栈（用于语法分析）
├── 线性有界自动机 LBA
└── 图灵机 Turing Machine —— 最强，能算一切可计算的问题
```

**一句话**：在编程中，自动机 ≈ 状态机 ≈ 有限状态机（FSM），说的都是同一回事。

## 总结

| 要点 | 说明 |
|:-----|:-----|
| **核心思想** | 用状态转移表代替一堆if-else，逻辑清晰 |
| **溢出处理** | 用long long存结果，每次累加后立即裁剪 |
| **为什么用状态机** | 规则多且有序时（如解析、词法分析），状态机比if-else优雅得多 |
| **终止态end** | 一旦进去就出不来了，后面所有输入直接忽略 |
