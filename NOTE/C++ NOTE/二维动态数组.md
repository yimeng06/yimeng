# 二维动态数组

## 核心概念

使用 `vector<vector<T>>` 实现的二维动态数组，T 为任意数据类型。

## 创建方式

```cpp
// 基本语法：vector<vector<T>> dp(m, vector<T>(n, value));

// 方形矩阵（n × n）
vector<vector<int>> dp(n, vector<int>(n));

// 矩形矩阵（m × n）
vector<vector<int>> dp(m, vector<int>(n));

// 指定初始值
vector<vector<int>> dp(m, vector<int>(n, -1));

// 初始化列表
vector<vector<int>> dp = {{1,2,3}, {4,5,6}, {7,8,9}};

// 逐步创建
vector<vector<int>> dp(m);
for (int i = 0; i < m; i++) dp[i].resize(n);
```

## 访问和修改

```cpp
dp[i][j] = 42;                    // 设置值
int value = dp[1][2];              // 获取值

// 边界检查
if (i >= 0 && i < dp.size() && j >= 0 && j < dp[0].size()) {
    dp[i][j] = value;
}
```

## 遍历方式

```cpp
// 下标遍历
for (int i = 0; i < dp.size(); i++) {
    for (int j = 0; j < dp[i].size(); j++) {
        cout << dp[i][j] << " ";
    }
}

// 范围for循环（推荐）
for (auto& row : dp) {
    for (int& val : row) {
        val *= 2;  // 修改
    }
}
```

## 常用操作

```cpp
// 获取大小
int rows = dp.size();
int cols = dp[0].size();

// 调整大小
dp.resize(m);
for (int i = 0; i < dp.size(); i++) dp[i].resize(n);

// 添加/删除行
dp.push_back(vector<int>(n, 0));
dp.pop_back();
dp.erase(dp.begin() + 1);

// 清空
dp.clear();
```

## 应用场景

```cpp
// 动态规划
vector<vector<int>> dp(n + 1, vector<int>(2, 0));

// 图的邻接矩阵
vector<vector<int>> adj_matrix(n, vector<int>(n, 0));
adj_matrix[0][1] = 1;  // 0到1有边

// 矩阵加法
vector<vector<int>> C(m, vector<int>(n));
for (int i = 0; i < m; i++) {
    for (int j = 0; j < n; j++) {
        C[i][j] = A[i][j] + B[i][j];
    }
}
```

## 性能考虑

| 操作 | 时间复杂度 |
|------|------------|
| 访问/修改 | O(1) |
| 遍历 | O(m × n) |
| 添加/删除行 | O(n) |
| 调整大小 | O(m × n) |

**空间复杂度**：O(m × n)

**优化建议**：
```cpp
// 预先分配空间
dp.reserve(m);

// 一维数组模拟（更高效）
vector<int> dp(m * n, 0);
int index = i * n + j;
```

## 总结

**关键要点**：
1. 创建：`vector<vector<int>> dp(m, vector<int>(n, value));`
2. 访问：`dp[i][j]`，注意边界检查
3. 遍历：范围for循环最简洁
4. 操作：获取大小、调整大小、添加删除元素
5. 应用：动态规划、图论、矩阵运算
6. 优化：预先分配空间，考虑一维数组模拟
7. 注意：边界检查、空数组处理、引用传递
