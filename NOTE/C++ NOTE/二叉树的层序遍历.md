# 二叉树的层序遍历

## 基础层序遍历

```cpp
class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        queue<TreeNode*> que;
        vector<vector<int>> res;
        if (root != nullptr) que.push(root);
        while (!que.empty()) {
            vector<int> tmp;
            for (int i = que.size(); i > 0; i--) {
                TreeNode* node = que.front();
                que.pop();
                tmp.push_back(node->val);
                if (node->left != nullptr) que.push(node->left);
                if (node->right != nullptr) que.push(node->right);
            }
            res.push_back(tmp);
        }
        return res;
    }
};
```

### 算法流程

1. **特例处理**：当根节点为空，则返回空列表 `[]`
2. **初始化**：打印结果列表 `res = []`，包含根节点的队列 `queue = [root]`
3. **BFS 循环**：当队列 `queue` 为空时跳出
4. **新建临时列表**：`tmp` 用于存储当前层打印结果
5. **当前层打印循环**：循环次数为当前层节点数（即队列 `queue` 长度）
6. **出队**：队首元素出队，记为 `node`
7. **打印**：将 `node.val` 添加至 `tmp` 尾部
8. **添加子节点**：若 `node` 的左（右）子节点不为空，则将左（右）子节点加入队列 `queue`
9. **保存结果**：将当前层结果 `tmp` 添加入 `res`
10. **返回值**：返回打印结果列表 `res`

```cpp
vector<int> vec;    // 动态数组，支持随机访问

```

### Queue（队列）用法

```cpp
queue<int> q;  // 创建整数队列

// 主要操作：
q.push(10);     // 入队：将元素加入队列尾部
q.pop();        // 出队：移除队列头部元素（注意：不返回被移除的元素！）
q.front();      // 获取队列头部元素（但不移除）
q.back();       // 获取队列尾部元素
q.empty();      // 判断队列是否为空
q.size();       // 获取队列中元素数量
```

### Deque（双端队列）用法

```cpp
deque<int> dq;  // 创建一个双端队列

// 两端插入
dq.push_front(1);   // 从前插入：队列变成 [1]
dq.push_back(2);    // 从后插入：队列变成 [1, 2]
dq.push_front(0);   // 从前插入：队列变成 [0, 1, 2]
dq.push_back(3);    // 从后插入：队列变成 [0, 1, 2, 3]

// 两端访问
cout << dq.front();  // 输出：0（前面元素）
cout << dq.back();   // 输出：3（后面元素）

// 两端删除
dq.pop_front();  // 移除0，队列：[1, 2, 3]
dq.pop_back();   // 移除3，队列：[1, 2]

// 随机访问（这是queue没有的功能！）
cout << dq[0];  // 输出：1（像数组一样访问）
cout << dq[1];  // 输出：2
```

**Queue vs Deque 主要区别**：
- Queue 只能在队尾插入、队头删除
- Deque 可以在两端插入和删除，还支持随机访问


## 锯齿形层序遍历

**题目**：返回二叉树节点值的锯齿形层序遍历（即先从左往右，再从右往左进行下一层遍历，以此类推，层与层之间交替进行）。

```cpp
class Solution {
public:
    vector<vector<int>> zigzagLevelOrder(TreeNode* root) {
        deque<TreeNode*> dq;
        vector<vector<int>> res;
        if (root != nullptr) dq.push_back(root);
        while (!dq.empty()) {
            // 打印奇数层（从左向右）
            vector<int> tmp;
            for (int i = dq.size(); i > 0; i--) {
                TreeNode* node = dq.front();
                dq.pop_front();
                tmp.push_back(node->val);
                // 先左后右加入下层节点
                if (node->left != nullptr) dq.push_back(node->left);
                if (node->right != nullptr) dq.push_back(node->right);
            }
            res.push_back(tmp);
            if (dq.empty()) break;
            // 打印偶数层（从右向左）
            tmp.clear();
            for (int i = dq.size(); i > 0; i--) {
                TreeNode* node = dq.back();
                dq.pop_back();
                tmp.push_back(node->val);
                // 先右后左加入下层节点
                if (node->right != nullptr) dq.push_front(node->right);
                if (node->left != nullptr) dq.push_front(node->left);
            }
            res.push_back(tmp);
        }
        return res;
    }
};
```

**思路**：
- 奇数层：从左向右打印，子节点按左→右顺序加入队尾
- 偶数层：从右向左打印，子节点按右→左顺序加入队首
- 使用双端队列实现灵活的前后操作

## 必要的头文件和结构体

```cpp
#include <vector>
#include <queue>
#include <deque>

struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
};
```
