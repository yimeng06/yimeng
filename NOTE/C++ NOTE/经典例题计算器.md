# 经典例题：计算器

## 问题描述

实现一个简单计算器，根据输入指令执行四则运算。

### 输入输出格式

**输入**：`操作符 数字1 数字2`

| 操作符 | 含义 | 输出 |
|:------:|:-----|:-----|
| `add` | 加法 | `x + y` |
| `sub` | 减法 | `x - y` |
| `mul` | 乘法 | `x * y` |
| `div` | 除法 | `x / y`（浮点数），除数为0输出`Error` |

### 示例

```
输入：add 5 3      输出：8
输入：sub 10 4     输出：6
输入：mul 6 7      输出：42
输入：div 10 2     输出：5
输入：div 10 0     输出：Error
```

---

## 核心算法：字符串解析与分派

### 处理流程

```
读取整行 → 按空格分割 → 提取[操作符, 数1, 数2] → 类型转换 → 分派运算 → 输出结果
```

### 关键步骤

1. **整行读取**：使用 `cin.getline()` 或 `getline()` （可包含空格）
2. **字符串分割**：遍历字符，以空格为分隔符提取3个字段
3. **类型转换**：`stoi()` 将字符串转为整数
4. **运算分派**：通过条件判断或函数映射执行对应操作
5. **边界处理**：除法检查除数为0

---

## 完整代码实现（基础版）

```cpp
#include <iostream>
#include <string>
#include <cstring>
#include <cstdlib>
using namespace std;

int main() {
    char str[100] = {0};
    cin.getline(str, sizeof(str));  // 安全读取整行
    
    string op, num1, num2;
    int space = 0;
    
    // 按空格分割字符串
    for (int i = 0; str[i]; i++) {
        if (str[i] == ' ') { space++; continue; }
        if (space == 0) op += str[i];           // 操作符
        else if (space == 1) num1 += str[i];    // 数字1
        else num2 += str[i];                    // 数字2
    }
    
    int x = stoi(num1), y = stoi(num2);
    
    // 运算分派（忽略大小写）
    if (strcasecmp(op.c_str(), "add") == 0)
        cout << x + y << endl;
    else if (strcasecmp(op.c_str(), "sub") == 0)
        cout << x - y << endl;
    else if (strcasecmp(op.c_str(), "mul") == 0)
        cout << x * y << endl;
    else if (strcasecmp(op.c_str(), "div") == 0) {
        cout << (y == 0 ? "Error" : to_string((double)x / y)) << endl;
    }
    
    return 0;
}
```

## 核心技术要点

### 1. 字符串分割技巧 ⭐核心

```cpp
// 方法：空格计数器标记当前字段
int space = 0;  // 空格计数器
for (int i = 0; str[i]; i++) {
    if (str[i] == ' ') { space++; continue; }  // 遇到空格，切换字段
    if (space == 0) op += str[i];              // 第0段：操作符
    else if (space == 1) num1 += str[i];       // 第1段：数字1
    else num2 += str[i];                       // 第2段：数字2
}
```

**原理**：
- 空格作为**分隔符**（delimiter）
- 计数器标识当前处于第几个**字段**（field）
- 时间复杂度 O(n)，n为字符串长度

### 2. 整行输入读取

```cpp
// cin >> 无法读取空格，必须用 getline
char str[100];
cin.getline(str, sizeof(str));  // C风格，需指定缓冲区大小

// 或使用C++ string（更安全）
string line;
getline(cin, line);  // 自动管理内存
```

**注意**：`sizeof(str)` 防止缓冲区溢出攻击

### 3. 大小写不敏感比较

```cpp
#include <cstring>
strcasecmp(op.c_str(), "add") == 0  // 返回0表示相等
```

**替代方案**（C++风格）：
```cpp
// 统一转小写再比较
transform(op.begin(), op.end(), op.begin(), ::tolower);
if (op == "add") { ... }
```

### 4. 类型转换与异常安全

```cpp
int x = stoi(num1);  // 字符串→整数

// 更安全的做法（处理非法输入）
try {
    int x = stoi(num1);
} catch (const invalid_argument&) {
    cout << "Invalid number" << endl;
} catch (const out_of_range&) {
    cout << "Number too large" << endl;
}
```

### 5. 除法边界处理

```cpp
// 必须检查除数！否则运行时错误（浮点例外或无穷大）
if (y == 0) 
    cout << "Error" << endl;
else 
    cout << (double)x / y << endl;  // 强制浮点除法
```

## 常见错误与陷阱

### ❌ 错误1：使用cin>>读取含空格的输入

```cpp
// 问题：cin>>遇到空格就停止，只能读到操作符
string op, num1, num2;
cin >> op >> num1 >> num2;  // 如果输入格式严格可用，但无法处理额外空格

// 正确：使用getline读取整行
cin.getline(str, sizeof(str));
```

### ❌ 错误2：字符串比较区分大小写

```cpp
// 问题：用户输入"ADD"无法匹配
if (op == "add") { ... }

// 正确：忽略大小写比较
if (strcasecmp(op.c_str(), "add") == 0) { ... }
```

### ❌ 错误3：整数除法截断

```cpp
// 问题：10/4=2而非2.5
cout << x / y << endl;

// 正确：强制转为浮点
cout << (double)x / y << endl;  // 或 static_cast<double>(x) / y
```

### ❌ 错误4：未检查除零

```cpp
// 致命错误：程序崩溃（Floating point exception）
cout << x / y << endl;

// 正确：先检查后运算
if (y == 0) cout << "Error" << endl;
else cout << (double)x / y << endl;
```

### ❌ 错误5：缓冲区溢出风险

```cpp
// 危险：未限制长度，可能越界写入
char str[100];
cin.getline(str);

// 安全：显式指定缓冲区大小
cin.getline(str, sizeof(str));
```

## 实现方案对比

### 方案1：手动字符串解析（已展示）

**适用**：学习字符串处理基础、面试手写代码  
**优点**：无需额外依赖，完全掌控细节  
**缺点**：代码较长，易出错

### 方案2：字符串流简化版 ⭐推荐（工程首选）

```cpp
#include <sstream>

int main() {
    string line, op;
    int x, y;
    
    getline(cin, line);        // 读取整行
    istringstream iss(line);   // 构造字符串流
    iss >> op >> x >> y;       // 自动按空格分割并类型转换
    
    if (op == "add") cout << x + y << endl;
    else if (op == "sub") cout << x - y << endl;
    else if (op == "mul") cout << x * y << endl;
    else if (op == "div") 
        cout << (y == 0 ? "Error" : to_string((double)x / y)) << endl;
    
    return 0;
}
```
**优势**：
- 代码量减少50%
- 自动处理类型转换
- 内置错误检测（如格式不匹配）
- 更符合C++惯用风格

### 方案3：函数映射表（扩展性强）

```cpp
#include <map>
#include <functional>

int main() {
    map<string, function<double(int,int)>> ops = {
        {"add", [](int a, int b){ return a + b; }},
        {"sub", [](int a, int b){ return a - b; }},
        {"mul", [](int a, int b){ return a * b; }}
    };
    
    string op; int x, y;
    cin >> op >> x >> y;
    
    if (op == "div")
        cout << (y == 0 ? "Error" : to_string((double)x/y)) << endl;
    else if (ops.count(op))
        cout << ops[op](x, y) << endl;
    else
        cout << "Unknown operation" << endl;
    
    return 0;
}
```
**优势**：
- 新增运算只需在map中添加一行
- 符合**开闭原则**（对扩展开放，对修改关闭）
- 适合运算符较多的场景

### 方案4：面向对象设计（大型项目）

```cpp
class Calculator {
private:
    map<string, function<double(double,double)>> operations;
public:
    Calculator() {
        operations["+"] = [](double a, double b){ return a+b; };
        operations["-"] = [](double a, double b){ return a-b; };
        operations["*"] = [](double a, double b){ return a*b; };
        operations["/"] = [](double a, double b){ 
            if (b == 0) throw runtime_error("Division by zero");
            return a/b; 
        };
    }
    
    double calculate(string op, double x, double y) {
        if (!operations.count(op)) 
            throw invalid_argument("Unknown operator: " + op);
        return operations[op](x, y);
    }
};
```
**优势**：高内聚低耦合，易于测试和维护  
**适用**：需要持久化状态、历史记录、撤销重做等高级功能

## 扩展应用场景

### 1. 支持更多数据类型（泛型计算器）

```cpp
template<typename T>
T calculate(string op, T x, T y) {
    if (op == "+") return x + y;
    if (op == "-") return x - y;
    if (op == "*") return x * y;
    if (op == "/") {
        if (y == 0) throw runtime_error("Div by zero");
        return x / y;
    }
    throw invalid_argument("Unknown op");
}

// 使用
auto r1 = calculate<int>("+", 5, 3);      // 8
auto r2 = calculate<double>("/", 10, 4);  // 2.5
```

### 2. 支持连续计算（交互式REPL）

```cpp
void runREPL() {
    string op; double x, y;
    while (cout << "> ", cin >> op >> x >> y) {
        try {
            cout << calculate(op, x, y) << endl;
        } catch (const exception& e) {
            cout << "Error: " << e.what() << endl;
        }
    }
}
```

### 最佳实践清单

#### ✅ 基础必做
- [ ] 使用 `getline` 读取整行输入（避免cin>>的空格问题）
