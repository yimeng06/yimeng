# 最长无重复字符子串（滑动窗口）

**题目**：找字符串中不含重复字符的**最长子串**长度。

```
"abcabcbb" → 3  ("abc")
"bbbbb"     → 1  ("b")
"pwwkew"    → 3  ("wke"，注意不是子序列"pwke")
""          → 0
```

## 思路：滑动窗口 + 哈希集合

维护一个窗口 `[i, rk]`，保证里面**没有重复字符**。右指针不断扩张，遇到重复就缩左边。

```
s = "a b c a b c b b"
      ↑       ↑
     i=0    rk=2   窗口[abc]，长度3，ans=3

i右移一步，删掉'a'：
      ↑         ↑
     i=1      rk=5   窗口[bcab]？不行！a重复了→实际是[abc]
                       长度还是3

每轮：左指针移一格(删字符) → 右指针尽量往右走(不重复就加) → 记录最大长度
```

```cpp
int lengthOfLongestSubstring(string s) {
    unordered_set<char> occ;    // 窗口里的字符（查重用）
    int n = s.size();
    int rk = -1, ans = 0;       // rk=右指针，还没开始动

    for (int i = 0; i < n; i++) {        // i=左指针，一步步往右
        if (i != 0)
            occ.erase(s[i - 1]);         // 左边门关上，放走一个字符

        while (rk + 1 < n && !occ.count(s[rk + 1])) {
            occ.insert(s[rk + 1]);      // 右边没重复？进来！
            rk++;                         // 右指针继续扩
        }
        // 此时窗口[i, rk]内无重复
        ans = max(ans, rk - i + 1);      // 更新最大值
    }
    return ans;
}
```

## 关键点解读

| 行 | 干什么 | 为什么 |
|:---|:-------|:-----|
| `occ.erase(s[i-1])` | 左移时扔掉左边的字符 | 窗口缩小，腾位置给右边 |
| `while (!occ.count(...))` | 下一个字符不在集合里？ | **不重复才让进** |
| `rk = -1` | 右指针从-1开始 | 这样第一次 `rk+1=0` 刚好指向首字符 |
| `rk - i + 1` | 当前窗口长度 | [i, rk] 闭区间的元素个数 |

> **核心**：每个字符最多被左指针踢出去一次、被右指针收进来一次 → O(n)。

---

## 复杂度

| | 复杂度 |
|:-:|:------:|
| 时间 | **O(n)** —— 每个字符进出集合各一次 |
| 空间 | **O(min(m,n))** —— m=字符集大小（ASCII就是128）|

## 总结

这道题是**滑动窗口的教科书级应用**：

- **unordered_set** 当"查重器"——O(1)判断有没有重复
- **左指针**每次走一步（有序），**右指针**贪婪地往前冲（遇阻即停
- 窗口大小 = 当前无重复子串长度，取max就是答案
