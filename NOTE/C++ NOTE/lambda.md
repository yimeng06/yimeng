# Lambda 表达式 —— "就地定义、用完即走"的临时函数

## 语法结构（三段式）

```
[捕获列表] (参数列表) -> 返回类型 { 函数体 };
   ↑           ↑            ↑          ↑
 能用外界的啥  调用时给啥    返回啥     干啥
```

### 1. 捕获列表 [] —— "我能用外面的啥？"

| 写法 | 含义 | 口诀 |
|:-----|:-----|:-----|
| `[]` | 啥都不用 | **两袖清风** |
| `[=]` | 全部拷贝一份 | **全都要，但都是复印件** |
| `[&]` | 全部引用（原文）| **"我全都要！"** |
| `[a, &b]` | 只要a(拷贝)和b(引用) | **挑着拿** |

### 2. 参数列表 () —— 和普通函数一样

### 3. 函数体 {} —— 写逻辑的地方

> **别忘了末尾的分号 `;`！** lambda是赋值给变量的语句，不是函数定义。

## 实战一：替代独立函数（sort排序最常用）

```cpp
// ❌ 传统写法：还得在外面单独定义一个函数
bool cmp(int a, int b) {
    return (a % 10) < (b % 10);      // 按个位数排序
}
sort(nums.begin(), nums.end(), cmp); // 把函数名传进去

// ✅ Lambda写法：就地定义，用完即走
vector<int> nums = {12, 43, 25, 71};
sort(nums.begin(), nums.end(),
    [](int a, int b) {               // 排序规则直接写在这！
        return (a % 10) < (b % 10);
    }
);
// 结果：[71, 12, 43, 25]（个位数1<2<3<5）
```

**好处**：不用跑到外面定义函数，阅读代码时**规则就在调用点旁边**，不用跳来跳去。

## 实战二：递归 Lambda（C++23 新语法）

Lambda想递归调自己？以前很麻烦，现在一行搞定：

```cpp
class Solution {
public:
    vector<int> rightSideView(TreeNode* root) {
        vector<int> ans;

        auto dfs = [&](this auto&& self, TreeNode* node, int depth) -> void {
            if (!node) return;

            if (depth == ans.size())       // 第一次到这个深度 → 记录！
                ans.push_back(node->val);

            self(node->right, depth + 1);   // 先右后左 → 每层第一个就是最右边
            self(node->left, depth + 1);
        };

        dfs(root, 0);
        return ans;
    }
};
```

### `this auto&&` 是什么鬼？

| 部分 | 作用 |
|:-----|:-----|
| `this` | 告诉编译器：这个lambda要递归调用自己 |
| `auto&&` | 完美转发，兼容所有类型 |
| `self` | 给"自己"起个名字，后面用 `self(...)` 递归 |

**本质**：编译器帮你生成了一个递归版本的lambda。以前要写一堆wrapper函数才能实现递归，现在一行搞定。

## 总结

| 场景 | 写法 | 说明 |
|:-----|:-----|:-----|
| **简单排序条件** | `[](int a,int b){...}` | 最常用，替代cmp函数 |
| **需要外部变量** | `[&](...){...}` | 引用捕获，方便改外部变量 |
| **递归** | `[&](this auto&& self,...){...}` | C++23新语法，二叉树DFS必备 |
| **即调即弃** | `[](int a,int b){return a+b;}(3,5)` | 定义完立刻调用，一次性工具人 |

> **口诀**：方括号抓外面，圆括号接参数，花括号写逻辑，末尾别忘分号。
