# 反转链表

## 题目一：反转链表

### 问题描述

给你单链表的头节点 `head`，请你反转链表，并返回反转后的链表。

**示例**：
- 输入：`head = [1,2,3,4,5]`
- 输出：`[5,4,3,2,1]`

### 算法思路

使用 **头插法（迭代法）** 来反转链表。

#### 核心思想
1. **维护三个指针**：
   - `pre`：指向当前节点的前一个节点（初始为 `nullptr`）
   - `cur`：指向当前节点（初始为 `head`）
   - `nxt`：指向当前节点的下一个节点（临时保存）

2. **反转过程**：
   - 保存 `cur->next` 到 `nxt`
   - 将 `cur->next` 指向 `pre`（反转指针）
   - 将 `pre` 移动到 `cur`
   - 将 `cur` 移动到 `nxt`

3. **循环终止**：当 `cur` 为 `nullptr` 时，`pre` 就是新的头节点

#### 图解过程

```
初始状态：
1 -> 2 -> 3 -> nullptr
pre  cur

第一步：
nullptr <- 1    2 -> 3 -> nullptr
         pre    cur

第二步：
nullptr <- 1 <- 2    3 -> nullptr
              pre    cur

第三步：
nullptr <- 1 <- 2 <- 3
                   pre    cur(nullptr)

最终：pre = 3（新的头节点）
```

### 代码实现

```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* pre = nullptr;
        ListNode* cur = head;
        
        while (cur) {
            ListNode* nxt = cur->next;  // 保存下一个节点
            cur->next = pre;             // 反转指针，把cur插在pre链表的前头
            pre = cur;                   // pre移动到cur
            cur = nxt;                   // cur移动到nxt
        }
        return pre;  // 返回新的头节点
    }
};
```

### 复杂度分析

- **时间复杂度**：O(n)，其中 n 是链表的长度。需要遍历链表一次。
- **空间复杂度**：O(1)，只使用了常数级别的额外空间。

### 递归解法（补充）

```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        if (!head || !head->next) {
            return head;
        }
        ListNode* newHead = reverseList(head->next);
        head->next->next = head;
        head->next = nullptr;
        return newHead;
    }
};
```

**递归思路**：
1. 递归反转 `head->next` 及之后的链表
2. 将 `head` 接到反转后的链表末尾
3. 返回新的头节点

**递归复杂度**：
- 时间复杂度：O(n)
- 空间复杂度：O(n)，递归调用栈的深度

## 题目二：反转链表 II

### 问题描述

给你单链表的头指针 `head` 和两个整数 `left` 和 `right`，其中 `left <= right`。请你反转从位置 `left` 到位置 `right` 的链表节点，返回反转后的链表。

**示例**：
- 输入：`head = [1,2,3,4,5], left = 2, right = 4`
- 输出：`[1,4,3,2,5]`

### 算法思路

使用 **哨兵节点 + 局部反转** 的方法。

#### 核心思想
1. **创建哨兵节点**：
   - 哨兵节点的 `next` 指向 `head`
   - 哨兵节点的作用是处理 `left = 1` 的情况，避免特殊处理

2. **找到反转区间的前驱节点**：
   - 从哨兵节点开始，向前移动 `left - 1` 步
   - 这个节点记为 `p0`，它的 `next` 就是要反转的区间的第一个节点

3. **局部反转**：
   - 在区间 `[left, right]` 内进行反转
   - 反转过程与题目一相同

4. **重新连接链表**：
   - 反转后的尾部连接到 `cur`
   - 反转后的头部被 `p0` 连接

#### 图解过程

```
初始状态：
dummy -> 1 -> 2 -> 3 -> 4 -> 5
         p0

找到p0后（left=2）：
dummy -> 1 -> 2 -> 3 -> 4 -> 5
         p0   cur

反转过程（right=4，反转3个节点）：
第一步：
dummy -> 1 -> 2    3 -> 4 -> 5
         p0   pre   cur

第二步：
dummy -> 1 <- 2    3 -> 4 -> 5
         p0        pre   cur

第三步：
dummy -> 1 <- 2 <- 3    4 -> 5
         p0             pre   cur

重新连接：
dummy -> 1 -> 4 -> 3 -> 2 -> 5
         p0        cur
```

### 代码实现

```cpp
class Solution {
public:
    ListNode* reverseBetween(ListNode* head, int left, int right) {
        // 创造哨兵节点的意义是防止left等于1的时候head要做反转
        // 创造一个哨兵节点 dummy，它的next指向head
        ListNode dummy(0, head);
        ListNode* p0 = &dummy;
        
        // 找反转区间前面的节点
        for (int i = 0; i < left - 1; i++) {
            p0 = p0->next;
        }

        ListNode* pre = nullptr;
        ListNode* cur = p0->next;
        
        // 反转区间内的节点
        for (int i = 0; i < right - left + 1; i++) {
            ListNode* nxt = cur->next;
            cur->next = pre;
            pre = cur;
            cur = nxt;
        }

        // 重新连接链表：反转后的尾部连接cur，反转的头部被p0连接
        p0->next->next = cur;
        p0->next = pre;
        
        return dummy.next;
    }
};
```

## 三种方法的对比

| 题目 | 方法 | 时间复杂度 | 空间复杂度 | 关键技巧 |
|------|------|------------|------------|----------|
| 反转链表 | 头插法（迭代） | O(n) | O(1) | 维护三个指针，逐个反转 |
| 反转链表 II | 哨兵节点 + 局部反转 | O(n) | O(1) | 找到前驱节点，局部反转后重新连接 |
| K个一组翻转链表 | 哨兵节点 + 分组翻转 | O(n) | O(1) | 统计节点数，分组翻转后重新连接 |

## 链表反转的关键点

### 1. 基本反转模式

```cpp
// 标准的三指针反转模式
ListNode* pre = nullptr;
ListNode* cur = head;
while (cur) {
    ListNode* nxt = cur->next;
    cur->next = pre;
    pre = cur;
    cur = nxt;
}
return pre;
```

### 2. 哨兵节点的作用

- **处理边界情况**：当需要反转的区间包含头节点时，哨兵节点可以简化代码
- **统一处理逻辑**：避免对头节点进行特殊处理
- **便于连接**：哨兵节点的 `next` 指向头节点，便于操作

### 3. 重新连接链表

反转后需要正确连接链表的前后部分：

```cpp
// 反转后的尾部连接到cur
p0->next->next = cur;

// 反转后的头部被p0连接
p0->next = pre;
```

### 4. 边界条件处理

- **空链表**：直接返回 `nullptr`
- **单个节点**：直接返回该节点
- **left = right**：不需要反转
- **k = 1**：不需要反转
- **节点数不足k**：保持原有顺序

## 常见变种题目

1. **判断回文链表**：找到中点，反转后半部分，比较前后两部分
2. **两两交换链表中的节点**：k=2的特殊情况
3. **旋转链表**：找到旋转点，断开链表，重新连接
4. **重排链表**：找到中点，反转后半部分，交替合并

## 总结

链表反转是链表操作中的基础问题，掌握好基本反转模式非常重要。

**关键要点**：
1. **三指针模式**：`pre`、`cur`、`nxt` 是反转链表的核心
2. **哨兵节点**：处理边界情况，简化代码逻辑
3. **局部反转**：找到反转区间的前驱节点，局部反转后重新连接
4. **分组翻转**：统计节点数，分组翻转后重新连接
5. **边界条件**：注意处理空链表、单个节点等特殊情况

**最佳实践**：
- 画图理解反转过程，特别是指针的变化
- 注意边界条件的处理
- 使用哨兵节点简化代码
- 反转后记得重新连接链表
- 测试各种边界情况

### 复杂度分析

- **时间复杂度**：O(n)，其中 n 是链表的长度。需要遍历链表一次找到反转区间，然后再反转区间内的节点。
- **空间复杂度**：O(1)，只使用了常数级别的额外空间。

### 关键点

1. **哨兵节点的作用**：处理 `left = 1` 的特殊情况，避免需要特殊处理头节点
2. **找到前驱节点**：从哨兵节点开始，向前移动 `left - 1` 步
3. **局部反转**：在区间内进行反转，与题目一的方法相同
4. **重新连接**：反转后需要正确连接链表的前后部分

## 题目三：K个一组翻转链表

### 问题描述

给你链表的头节点 `head`，每 `k` 个节点一组进行翻转，请你返回修改后的链表。

`k` 是一个正整数，它的值小于或等于链表的长度。如果节点总数不是 `k` 的整数倍，那么请将最后剩余的节点保持原有顺序。

**示例**：
- 输入：`head = [1,2,3,4,5], k = 2`
- 输出：`[2,1,4,3,5]`

### 算法思路

使用 **哨兵节点 + 分组翻转** 的方法。

#### 核心思想
1. **统计节点个数**：
   - 遍历链表，统计总节点数 `n`
   - 用于判断是否还有足够的节点进行翻转

2. **创建哨兵节点**：
   - 哨兵节点的 `next` 指向 `head`
   - `p0` 指向哨兵节点，用于连接翻转后的组

3. **分组翻转**：
   - 每次处理 `k` 个节点
   - 在组内进行反转
   - 反转后重新连接链表
   - `p0` 移动到下一组的头部

4. **处理剩余节点**：
   - 当剩余节点数小于 `k` 时，保持原有顺序

#### 图解过程

```
初始状态（k=2）：
dummy -> 1 -> 2 -> 3 -> 4 -> 5
p0      cur

第一组翻转：
dummy -> 2 -> 1 -> 3 -> 4 -> 5
         p0       cur

第二组翻转：
dummy -> 2 -> 1 -> 4 -> 3 -> 5
                  p0       cur

剩余节点数=1 < k=2，不翻转
最终结果：
dummy -> 2 -> 1 -> 4 -> 3 -> 5
```

### 代码实现

```cpp
class Solution {
public:
    ListNode* reverseKGroup(ListNode* head, int k) {
        // 统计节点个数
        int n = 0;
        for (ListNode* cur = head; cur; cur = cur->next) {
            n++;
        }
        
        ListNode dummy(0, head);
        ListNode* p0 = &dummy;
        ListNode* pre = nullptr;
        ListNode* cur = head;

        // k个一组处理
        for (; n >= k; n -= k) {
            // 反转k个节点
            for (int i = 0; i < k; i++) {
                ListNode* nxt = cur->next;
                cur->next = pre;
                pre = cur;
                cur = nxt;
            }
            // 重新连接链表
            ListNode* nxt = p0->next;
            p0->next->next = cur;
            p0->next = pre;
            p0 = nxt;  // p0指向下一组的头部
        }
        return dummy.next;
    }
};
```
