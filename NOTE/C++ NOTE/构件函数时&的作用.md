# 构造函数时 & 的作用

在C++中，函数参数传递方式主要有三种：值传递、引用传递和常量引用传递。`&` 符号的使用对性能和安全性都有重要影响。

## 1. 值传递（没有 &）

### 基本概念

```cpp
void func(string str) { ... }
```

### 特点

- **创建副本**：调用时，实参会被复制一份传给函数
- **修改不影响原值**：函数内对参数的修改不会影响调用者的原始数据
- **有性能开销**：复制大对象（如长字符串、vector等）可能较慢

### 代码示例

```cpp
#include <iostream>
#include <string>
using namespace std;

void modifyByValue(string str) {
    str = "modified";  // 修改的是副本
    cout << "函数内: " << str << endl;
}

int main() {
    string original = "original";
    modifyByValue(original);
    cout << "函数外: " << original << endl;  // 输出: original
    return 0;
}
```

### 适用场景

- 参数是基本数据类型（int, double, char等）
- 需要保护原始数据不被修改
- 参数对象较小，复制开销可以接受

### 性能分析

```cpp
// 对于大对象，值传递会有明显的性能开销
void processLargeVector(vector<int> vec) {  // 复制整个vector
    // 处理vec
}

// 测试：传递100万个元素的vector
// 值传递：需要复制100万个int，约4MB内存
// 引用传递：只传递指针，8字节
```

---

## 三种传递方式的对比

| 特性 | 值传递 | 引用传递 | 常量引用传递 |
|------|--------|----------|--------------|
| 语法 | `void func(T param)` | `void func(T& param)` | `void func(const T& param)` |
| 是否复制 | 是 | 否 | 否 |
| 能否修改 | 能修改副本 | 能修改原值 | 不能修改 |
| 性能 | 较低（大对象） | 高 | 高 |
| 安全性 | 高 | 低 | 高 |
| 适用场景 | 基本类型、小对象 | 需要修改原值 | 只读访问、大对象 |
| 接受右值 | 是 | 否 | 是 |

## 最佳实践

### 1. 选择原则

```cpp
// ✅ 基本数据类型：使用值传递
void processInt(int num) { ... }
void processDouble(double value) { ... }

// ✅ 小对象（如pair）：可以使用值传递
void processPair(pair<int, int> p) { ... }

// ✅ 大对象（如string, vector）：使用常量引用传递
void processString(const string& str) { ... }
void processVector(const vector<int>& vec) { ... }

// ✅ 需要修改原值：使用引用传递
void modifyString(string& str) { ... }
void modifyVector(vector<int>& vec) { ... }

// ✅ 只读访问大对象：使用常量引用传递
void printString(const string& str) { ... }
void printVector(const vector<int>& vec) { ... }
```

### 2. 常见错误和注意事项

```cpp
// ❌ 错误1：对基本类型使用引用传递（无性能提升）
void processInt(int& num) { ... }  // 不推荐
// 正确：基本类型使用值传递
void processInt(int num) { ... }   // 推荐

// ❌ 错误2：对只读参数使用非const引用（不安全）
void printString(string& str) { ... }  // 不安全
// 正确：使用const引用
void printString(const string& str) { ... }  // 安全

// ❌ 错误3：传递临时对象给非const引用
void modifyString(string& str) { ... }
modifyString("hello");  // 编译错误！
// 正确：使用const引用
void printString(const string& str) { ... }
printString("hello");  // 正确

// ❌ 错误4：在const引用中修改对象
void modifyConstReference(const string& str) {
    str = "modified";  // 编译错误！
}

// ❌ 错误5：返回局部变量的引用
string& dangerousFunction() {
    string local = "hello";
    return local;  // 危险！返回局部变量的引用
}
// 正确：返回值或const引用
string safeFunction() {
    string local = "hello";
    return local;  // 正确：返回值
}
```

## 总结

### 核心要点

1. **值传递**：
   - 适用于基本数据类型和小对象
   - 创建副本，不影响原值
   - 有性能开销，但安全性高

2. **引用传递**：
   - 适用于需要修改原值的情况
   - 无复制开销，性能高
   - 可以修改原值，但安全性较低

3. **常量引用传递**：
   - **最佳实践**：适用于大多数情况
   - 无复制开销，性能高
   - 不能修改原值，安全性高
   - 可以接受左值和右值

### 选择建议

```cpp
// 📋 决策树
if (需要修改原值) {
    使用引用传递 (T&)
} else if (对象较大) {
    使用常量引用传递 (const T&)
} else {
    使用值传递 (T)
}
```

### 记忆口诀

> **基本类型用值传，大对象用const引用，要修改就用引用传。**

### 最终建议

1. **默认使用常量引用传递**：这是最安全且高效的方式
2. **基本类型使用值传递**：无性能差异，代码更简洁
3. **需要修改时使用引用传递**：明确表达修改意图
4. **避免不必要的复制**：大对象一定要用引用传递
5. **注意const的正确使用**：保护数据不被意外修改
