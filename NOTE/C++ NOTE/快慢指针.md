# 快慢指针技巧

**核心思想**：两个指针以不同速度遍历链表，slow每次走1步，fast每次走2步。

---

## 一、找链表中点

**题目**：返回链表的中间节点（偶数个则返回第二个）。

```cpp
ListNode* middleNode(ListNode* head) {
    ListNode* slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;           // 慢针走1步
        fast = fast->next->next;     // 快针走2步
    }
    return slow;
}
```

**原理**：fast走完时，slow恰好在中间。时间O(n)，空间O(1)。

---

## 二、判断链表是否有环

**题目**：判断链表是否存在环。

```cpp
bool hasCycle(ListNode* head) {
    ListNode* slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (fast == slow) return true;  // 相遇则有环
    }
    return false;                       // fast走到头则无环
}
```

**原理**：无环时fast会到达nullptr；有环时fast最终会追上slow（像跑道上的两人）。

---

## 三、找环的入口节点

**题目**：返回环的起始位置，无环返回null。

```cpp
ListNode* detectCycle(ListNode* head) {
    ListNode* slow = head, *fast = head;

    // 第一阶段：找相遇点
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (fast == slow) {             // 相遇后进入第二阶段
            // 第二阶段：head和slow同速走，相遇点即入口
            while (head != slow) {
                head = head->next;
                slow = slow->next;
            }
            return slow;
        }
    }
    return nullptr;
}
```

**数学原理**：
- 设：头→入口=a步，入口→相遇=b步，环长=c
- fast走了 2(a+b)，slow走了 (a+b)
- fast比slow多走的 = a+b = kc（k圈）
- 所以 a = kc-b，即从相遇点再走a步=回到入口
- 因此让head和slow同时走a步，必在入口相遇

## 四、重排链表

**题目**：`L0→L1→…→Ln` 变为 `L0→Ln→L1→Ln-1→L2→…`

```cpp
class Solution {
    ListNode* middleNode(ListNode* head) {       // 找中点
        ListNode* slow = head, *fast = head;
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
        }
        return slow;
    }

    ListNode* reverseList(ListNode* head) {     // 反转后半段
        ListNode* pre = nullptr, *cur = head;
        while (cur) {
            ListNode* nxt = cur->next;
            cur->next = pre;
            pre = cur;
            cur = nxt;
        }
        return pre;
    }

public:
    void reorderList(ListNode* head) {
        ListNode* mid = middleNode(head);       // 1.找中点
        ListNode* head2 = reverseList(mid);     // 2.反转后半段

        while (head2->next) {                   // 3.交替合并
            ListNode* nxt = head->next;
            ListNode* nxt2 = head2->next;
            head->next = head2;
            head2->next = nxt;
            head = nxt;
            head2 = nxt2;
        }
    }
};
```

---

## 总结

| 题目 | 核心思路 | 关键 |
|:-----|:---------|:-----|
| **找中点** | fast到终点时slow在中点 | `while(fast&&fast->next)` |
| **判环** | 有环则fast必追上slow | 相遇即有环 |
| **找入口** | 数学推导：再走a步回入口 | 两阶段算法 |
| **重排链表** | 找中点+反转+合并 | 三步组合拳 |

**通用模板**：
```cpp
ListNode* slow = head, *fast = head;
while (fast && fast->next) {
    slow = slow->next;
    fast = fast->next->next;
    // 根据题目需求在此处添加逻辑
}
```
