# 滑动窗口（同向双指针）

**核心思想**：左右指针都往右走，维护一个"窗口"，右扩左缩，像毛毛虫一样蠕动。

---

## 一、最小长度子数组（和 ≥ target）

**题目**：找长度最小的、和 ≥ target 的连续子数组。

```cpp
int minSubArrayLen(int target, vector<int>& nums) {
    int n = nums.size(), left = 0, sum = 0;
    int ans = n + 1;          // 先设个不可能的值

    for (int right = 0; right < n; right++) {
        sum += nums[right];            // 右边口张开，吃进新元素

        while (sum >= target) {         // 吃撑了？缩左边！
            ans = min(ans, right - left + 1);  // 记录最小长度
            sum -= nums[left];          // 左边吐出一个
            left++;                     // 左边界右移
        }
    }
    return ans <= n ? ans : 0;          // 没找到就返回0
}
```

**流程**：right不断右移扩大窗口 → sum够了就开始left右移缩小窗口 → 记录最小值。时间O(n)，每个元素最多进出窗口各一次。

## 二、乘积小于K的子数组个数

**题目**：乘积严格小于k的连续子数组有多少个？

```cpp
int numSubarrayProductLessThanK(vector<int>& nums, int k) {
    if (k <= 1) return 0;     // k≤1时，正数乘积永远≥k，直接0

    int ans = 0, prod = 1, left = 0;

    for (int right = 0; right < nums.size(); right++) {
        prod *= nums[right];

        while (prod >= k) {           // 乘积超了？左边缩！
            prod /= nums[left];
            left++;
        }
        // 关键：以right为右端点的合法子数组有 (right-left+1) 个
        ans += right - left + 1;
    }
    return ans;
}
```

### 为什么 `ans += right - left + 1`？（重点）

不用全量数，用**增量法**——每次只算新增的部分：

```
窗口 [1,2,3] → 右移 → [1,2,3,4]
新增元素4后，以4为右边界的合法子数组：
  [4], [3,4], [2,3,4], [1,2,3,4]   ← 共4个 = 窗口大小
```

所以每次 `ans += 窗口大小`，既不重复也不遗漏。

## 总结

| 题目 | 窗口条件 | 缩窗操作 | 结果 |
|:-----|:---------|:---------|:-----|
| **最小长度子数组** | `sum ≥ target` | `sum -= nums[left++]` | 取 `min(长度)` |
| **乘积小于K** | `prod ≥ k` | `prod /= nums[left++]` | **累加窗口大小** |

**滑动窗口通用模板**：
```cpp
for (int right = 0; right < n; right++) {

}
```
